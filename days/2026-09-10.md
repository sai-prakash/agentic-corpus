Cross-substrate authority (2609.08472, Li / Volkov / Liu / Xu / Chen / Zhou / Shao / Sun / Lu, 8 Sep): planner-visible memory is not the authority store. An agent can persist model-visible notes and mutate a workspace while a runtime, registry, or approval service holds the grant that actually licenses the next write. Identical final files can then require opposite safe actions. Two mini-benchmark families, real Git lineage, durably recorded attempts, deterministic oracles, two model routes. Experiment 1 (128-cell evidence ablation): authority-blind candidate evidence 0/32 final semantic success; raw receipts and a typed relation both 32/32 — the missing authority fact accounts for the gain; typed packaging adds no planning accuracy over equal raw information. Experiment 2 (96 planning calls): workspace-visible evidence yields 12/16 unsafe publication decisions; planning with the typed relation stays unreliable (15/32 first actions correct; 11/32 invalid or absent). Experiment 3 replays the same 32 first-action intents with zero extra model calls: a deterministic execution guard blocks all six unsafe intents and permits all 12 valid authorized publishes. Authority enforcement belongs at the mutation boundary. Pair with EAL: that paper is a *memory row* minting a grant the history never issued; this paper is a *grant that never entered the planner's store*. Pair with Persistent Agents: identity+memory+body can move; the approval service may not have moved with them.

Procedural Graphs (2609.09153, Lu / Chen / Wu / Arık, 8 Sep): a knowledge graph is not a procedure graph. Facts are (entity, relation, entity) for what-is; procedures are (procedure, relation, procedure) for what-to-do. At each step the framework localizes the active node; a guidance model renders the surrounding subgraph as situational bias, not a dictated action. An LLM refiner contrasts failed vs successful traces and edits topology; commits only if held-out validation does not drop; rejected edits stay in memory so the loop does not retry them. Starting from a minimal skeleton, evolved graphs match or beat hand-designed ones and can repair a flawed expert prior. Reported cells: PG wins 19/24 settings vs strongest baseline (binomial p=4.3×10⁻⁴). BFCL v3 Gemini 3.5 Flash 67.00 vs 58.00; GDPval Gemini 3.1 Pro 78.78 vs 71.37; τ-bench Gemini 3.1 Pro 80.00 vs 73.04. EnterpriseArena full-horizon survival: Claude Sonnet 4.6 58.0 vs 44.0; Gemini 3.1 Pro 34.0 vs 6.0. Graph sizes typically 7–17 nodes / 7–27 triplets (BFCL v3 131 / 265). No public repo in the comments. Pair with TROVE: that fences the *remaining route* after a commit; this *is* the route the solver is allowed to see. Pair with Trace2Tower: that compiles a library from traces; this compiles an execution graph the library would walk.

Subagents vs Agent Skills (2609.09233, Piriyakulkij / Lawrence / Curth / Karmalkar / Prasad, 7 Sep): loading `SKILL.md` into the parent context is not invoking a skill. SkillsBench 64-task subset, OpenHands harness, synthesized packages that carry an I/O contract vs curated packages that do not. When the package exposes a contract and encodes the procedure that fulfills it, spawning a fresh-context subagent beats in-context skill execution; the gap is largest on bandwidth-limited models. On curated packages without contracts, in-context skills match or win. Subagents cut peak context on >80% of tasks for GPT-5.3 Codex and Kimi K2.6, and pay for it in coordination tokens. Pair with Visual Studio Agent Skills: Copilot's default is the in-context load. Pair with Warp inner/outer: the outer loop still has to choose the *invocation shape*, not only the file text.

Audit Without Verification (2609.07680, Arslan, 7 Sep; github.com/Polpii/FaultLine, MIT): an accountability layer that reads peer conclusions is not a check. Six-agent pipelines, process-level information boundaries, 345,600 requests per chain model, two models. Zero allegations in 7,996 clean silent episodes. When a false alarm fires in an otherwise clean run, an innocent party is named in 34.4% and 62.6% of cases by chain. Auditors recover the true origin from reports 4.1% of the time (below 20% uniform guess and 31.0% best fixed-link accuser) but 60.3% from raw documentation. Deleting agents' conclusions lifts accuracy 4.1 → 45.2 (+41.2 pp, 95% CI +35.3 to +46.9) and drops adherence 94.4% → 3.4%. Harm replicates on two auditors and a second domain. Pair with ClaimReceipt / SWE-Gate: a missing receipt is INCONCLUSIVE; a relayed accusation is worse — it looks like a receipt.

Discovery Certification Protocol (2609.09219, Ning / Zhong / Li / Zeng, 7 Sep): a leaderboard score is not a discovery. Gate 1: useful improvement on sealed eval. Gate 2: matched agents get registered start state and observed web content, not the target research history; any valid method that hits the numerical target is a recovery witness and triggers Core veto. DCP Core wants adequate controls, zero observed recoveries, and a finite-sample bound on recovery in one fresh registered episode. Two controlled audits (SQLite optimization, virtual catalyst control): 0/96 recoveries, upper bound 0.0468. Paired truthful-vs-neutral feedback: 30 truthful recoveries, 0 neutral, passing 60-pair null studies. A deterministic LLM-free verifier reproduces the decision from frozen evidence. Pair with Multi-Harness RL: the eval cage is the dominant variable; DCP asks whether the *method* can be recovered without the author's hidden path.

CAPMAS (2609.06500, Veski / Guerraoui / Froelicher, 6 Sep): a natural-language query is not a privilege set. Contrastive semantic scoping maps the query onto a bounded bundle before execution; Macaroon tokens then delegate offline with monotonic reduction. Reported vs OAuth 2.0 Token Exchange: ~30× faster delegation ops, ~2× less delegation latency, up to 3× lower bandwidth. >90% perfect privilege-bundle retrieval in 17 ms on 3,100+ endpoint schemas; 99.5% fewer unnecessary privileges than "give the agent the user's full grant." Pair with EAL and XSA: scoping the query is necessary; it does not put the grant on the mutation boundary.
