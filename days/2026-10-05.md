Harness Learning (2609.35738, Zhang / Liu / Wang / Tajwar / Arora / Salakhutdinov / Khashabi / Song / Zanette, CMU / JHU / Stanford, submitted 28 Sep; recap @saiitoshii status 2106919271226015773, 5 Oct): a weight update is not a harness revision. The solver stays frozen. A proposer is trained to rewrite the solver's harness from execution feedback, treated as meta-learning over executable programs. On 21 unseen Reasoning Gym families, SFT then RL lifts mean single-step held-out score from 0.32 (untrained proposer) to 0.62. Under that same single-step protocol the 4B proposer beats its 35B teacher on average (0.62 vs 0.56). The teacher is higher when an oracle picks its best of eight proposals. The main set excludes five further unseen families the authors call hard for both proposers and the teacher. Multi-hop QA transfers from HotpotQA to MuSiQue and 2WikiMultihopQA; the abstract does not give those point deltas. No code URL on the abs page. Heat 5 under harness-learning. Pair with ActiveSaddler (2610.00906): that loop keeps the optimizer fixed and changes which scenario teaches it. Pair with Harness Annealing (2610.01235): that loop tries to move control into the weights. This loop leaves the weights alone and edits the cage at test time. Do not read 0.62 as a new base solver.

VISTA (2610.02200, Qiushi Han / Keya Hu / Linlu Qiu / Cathy Wu / Kaiming He, submitted 1 Oct, author post @JoshHanHi status 2106536875586404707 on 4 Oct + github.com/joshhhhhan/VISTA + https://vista-research.github.io/): a caption of the frame is not the frame. VISTA is a visual harness that lets a general multimodal model see the environment and keep a lossless visual memory of past observations in original form, then retrieve and reorganize those frames while it reasons. On ARC-AGI-3 it moves Claude Opus 5.0's Relative Human Action Efficiency from 40.68 to 100.00, completing all 25 public games with 57.4% fewer actions than first-time human participants. The same design extends to three further visual game and puzzle benchmarks with minimal adaptation, beating minimal harnesses on the same model. The abstract does not print those three deltas. Heat 5 under visual-harness. Pair with Mem++ (2610.02002): one refuses to compress a document before the question names a time; this refuses to compress a frame before the next look. Do not read 100.00 as a new model.

Process-level skill eval (2610.01833, Vo / Doshi / Sheinin, submitted 1 Oct): a final number is not a trajectory. Enterprise skills drift when APIs, models, and specs change, and an outcome check can miss that. On Revenue and Productivity variants of a Business Value Determination skill, 240 trials span two skills, two spec variants, two harnesses, and three models. Of 175 trials that pass every applicable final numerical check, 162 (92.6%; Wilson 95% CI 87.7–95.6) still contain another evaluator-detected deviation. Under a broader seven-check final-state definition, 151 of 164 passing runs (92.1%; CI 86.9–95.3) still fail a trajectory check. Dependency attribution cuts mean failed checks per run from 6.34 to 2.65 roots. Spec sensitivity depends on model and harness. Longitudinal validation under real API change is future work. No code URL. Heat 5 under trajectory-gate. Pair with Keyword Harnesses Fail Open (2610.02142): one shows a lenient string score can credit a call that never happened; this shows a passing final can hide a bad tool order. The ladder is still minutes. Add the trajectory check before you trust the number.

MCRI (2610.01506, Yang / Xintong / Xu / Wang / Lin / Li / Liu, submitted 1 Oct): a pre-execution skill score is not an execution. MCRI-Eval ranks skills on information gain and behavioral constraint before they run. On 63,812 public skills from the OpenClaw skill hub, 58,275 skill-conditioned executions across BigCodeBench, BFCL-Fundamental, and Mind2Web. Scores track community popularity and have the highest downstream ranking agreement of the methods they compare. Top-1 selection advances 17.7, 22.8, and 19.6 percentile points in downstream performance rank versus the strongest baseline on each benchmark. No code URL. Heat 4 under skill-prior. Pair with the process-level paper: one chooses which skill is worth running; the other refuses to stop at the final number after it runs. Do not read the percentile points as absolute accuracy.

CIR (2610.00372, Xiao / Wang / Chen / Chao / Cui / Qian / Mei / Meng / Yu / Yin, submitted 30 Sep): average recovery is not a causal recovery. The same intervention can rescue a failing trajectory or break one that would have succeeded. CIR decides from pre-recovery information whether to intervene. On long-horizon ALFWorld with Qwen3-14B, success moves from 70.33% to 73.33%. Trajectories that already had correct observations are left untouched. Extra controls say the gain is not just the new observation. No code URL. Heat 4 under recoverable-harness. Not a concept file: one paper, no second source in the window. Pair with Mid-Harness (2609.39982) only as a sibling — that one verifies the action; this one asks whether recovery is worth firing.
