# 2026-11-21

**GrepMem (Lossless append-only log + regex search is not structured or lossy memory)**: arXiv:2611.25123 (Ziyan Yang, Taiwei Shi, Jieyu Zhao / USC, submitted 18 Nov 2026). Keeps the agent's complete history as plain text and recalls via a regular-expression tool; no embeddings, index, or extra models. After RL on Qwen3.5-9B, 95–97% on ContextBench versus at most 21% for lossy baselines; +8.8 points on BCP-Multi; remains on the accuracy–token-cost Pareto frontier. Contrast: summarization decides what to keep before the query is known. Heat 5. Paper + high-engagement X from @dair_ai (124 likes, 147 bookmarks) plus multiple independent posts.

**ClonAct (Context blocks as virtualized schedulable resources is not a linear session or router hierarchy)**: arXiv:2611.26346 (Xufei Tian, Han Hu, Wenli Du, submitted 19 Nov 2026) with shipping repo and blog. Routerless architecture virtualizes Context Cells via a Context MMU, Synaptic Bus, and isolated trial-merge gate behind one interface. Trial merge lifts true-conflict merges to 63.3%; overall virtualization uses 45.9% fewer prompt tokens and avoids compact-model router collapse. Contrast: single-session constraint bleed and lossy ticket handoffs are not direct context virtualization. Heat 4. Paper + GitHub + blog.

**AutoRAGBench (Agents that build and iterate RAG systems from scratch is not a fixed pipeline)**: arXiv:2611.25582 (submitted 19 Nov 2026). Nine open-code tasks where agents analyze data, implement pipelines, and refine under a six-hour H800 budget with no starter code. GPT-6.1 Sol + Codex CLI averages 56.1 versus 44.4 Human-SOTA composite; starting from human systems improves +16.6 points on seven tasks. Contrast: prescribed RAG templates are not autonomous system development. Heat 4. Paper + public code release.
