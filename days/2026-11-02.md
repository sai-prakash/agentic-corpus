DeepSeek dsh-superagent-prototype (GitHub deepseek-ai/dsh-superagent-prototype, released 31 Oct 2026, MIT, research prototype): proactive coding agent for one GitHub repo packaged as a DeepSeek Harness bundle. Router listens to GitHub (optional Feishu), opens work items for authorized requests, Workers run in isolated sessions/directories, answers in the original thread (e.g. PR). Web panel for human attention. Design goal: minimize human attention, act only on explicit asks or rules. Companion article on Super-agent architecture (Router-Worker, attention budget). Simulation claim: p95 task completion 15.7 min vs 29.5 min single-session with subagent. Contrast: proactive Router-Worker with isolated sessions is not a single-session coding agent or always-on unsupervised loop. Heat 4. Shipping repo + architecture writeup.

Notion Lore shared memory (makenotion/lore, MIT; Notion blog; recirculated on X ~1 Nov): persistent shared memory for agents backed by Notion databases (Projects, Topics, Memories, Entities, Facts). MCP tools + CLI + hooks for wake-up and auto-save. Any MCP harness can read/write the same vault; humans edit in Notion. Contrast: shared multiplayer memory is not per-session local notes or opaque vector store. Heat 4. Product + open-source repo.

Microsoft ReCAP persistent context graphs for memory compaction (Microsoft Research, Sept 2026 / recirculated): stores attention-derived importance scores and dependency links in a lightweight persistent context graph. Selects messages for new requests without extra model calls. Reduces estimated compaction/restoration latency ~95% vs Codex default summarization on Qwen3-Coder and gpt-oss. Contrast: attention-derived persistent graph is not full re-summarization or KV recompression on every request. Heat 4. Paper + product trace.

On ODAC-Vis (640 tasks), single round lifts executability +28.02 and chart structure +34.01. Contrast: harness revision from traces is not weight update. Heat 4.
