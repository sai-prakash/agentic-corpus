Anthropic "Building agents: When to fold subagents into your main agent loop" (22 Oct https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop; companion kit https://github.com/anthropics/single-agent-loop-kit): across enterprise deployments a single agent loop with progressive skill/tool disclosure frequently beat both one-prompt and multi-subagent designs on quality, often at lower cost and latency (one customer ~2× faster). Subagents remain for context-bloat degradation, parallel disposable contexts, or tool-selection conflicts from conflicting instructions. Migration measures before/after on shared e2e evals; fold one specialist at a time into skills + tools. Contrast: progressive disclosure of skills is not a subagent loop. Heat 5. Concept written. Independent of the 22 Oct AAIF donation of the skill standard itself.

FastHarness (arXiv:2610.31427, submitted 22 Oct, Lin et al.): experience-driven adaptive review scheduling for frozen VLA policies (π0.5 + GPT-6 Astra supervision). Fast path reduces review frequency as stage memory and reviewed outcomes accumulate; recovery path focuses supervision on errors. Across four simulated manipulation tasks: reviewer tokens −57.2% per task, mean episode time 85.5 → 52.0 min, success 80% → 97.19% vs GPT-as-Policy. Signal for adaptive supervision inside a harness rather than constant review. Heat 4.

MHG-Mem (arXiv:2610.29995, submitted 21 Oct): provenance-preserving multimodal hypergraph memory. Entity mentions + facts as nodes, occurrence/evolutionary/evidential hyperedges for identity, state evolution, and visual evidence. Hypergraph agentic search selects entry layer and traverses typed edges, inspecting source observations when needed. Improves 8.20–9.98% over strongest baseline on three benchmarks. Continues structured memory / context-graph theme. Heat 4.

Harness Scaling (arXiv:2610.29458, submitted 21 Oct, Bai et al.): new scaling dimension for agentic RL — train across a factorized harness space (diverse execution configs) rather than a single harness. Improves generalization to unseen white-box configs and transfers to external black-box harnesses better than single complex black-box training. Signal that harness diversity is a training axis, not only a test-time choice. Heat 3.

LearnHarness (shipping desktop app https://learnharness.ai/ + GitHub amosblomqvist/learnharness; X post @amosblomqvist 23 Oct): specialized agent harness for learning. Probe → plan (minimal dependency tree) → teach (predict/explain/check one reasoning step) → adaptive practice; persistent graph of propositions and reasoning chains shared across sessions. Local plain files, visible prompts, own keys. Signal for domain-specific harnesses that externalize the learner's mental model as a graph. Heat 3.

Krusch Context MCP (https://github.com/kruschdev/krusch-context-mcp; X discussion 23 Oct): local SQLite-first MCP for coding agents. Five canonical verbs (retrieve, remember, revise, nudge, health) keep architectural decisions, invariants, lessons, and bug diagnoses available across sessions with temporal lineage and pre-commit audits against active rules. Pairs with memory-lifecycle / agent-skills patterns. Heat 3.
