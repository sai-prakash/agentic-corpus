# 2026-10-31

FIRME registry-anchored memory graphs (arXiv:2610.40482, Zhang et al., submitted 29 Oct): a memory graph that reconciles heterogeneous observations (different surface forms across sources and periods) to persistent canonical relationships while retaining source, time, and context. Rule-based within-period fusion plus cross-period aliases and deterministic evolution updates. On investor-call/cash-flow data and S&P 500 transcripts, +7.8–12.1 pp final-period Correct Match Rate vs a historical registry; human audit shows further gains in match rate and reattachment recall. Contrast: identity-preserving registry memory is not flat episodic notes. Heat 4. Paper only so far.

FoG evidence-coverage training for KG agents (arXiv:2610.37405, Sun et al., submitted 27 Oct): existing KG agents often answer correctly without retrieving supporting triples. FoG uses evidence-grounded synthesis (hide entities behind verifiable sub-questions), a KG interaction agent that records returned triples, and an evidence-coverage process reward (ECPR) that credits the first retrieval of each supporting triple. 3B–4B models beat larger baselines on answer accuracy and evidence coverage across three KGQA benchmarks, with zero-shot cross-KG transfer. Contrast: training for evidence retrieval is not answer-only RL. Heat 4. Paper.

EMBRACE embedded-browser risk in agent tools (Forever Security blog 29 Oct by Gal Weizman; coverage 30 Oct): AI coding assistants (Cursor, GitHub Copilot, Codex, VS Code, Claude Desktop) ship enriched embedded browsers that break standard browser threat models, enabling arbitrary code execution, local file exfiltration of SSH keys/.env, prompt injection, and address-bar spoofing. Cursor and Copilot patched; Codex and VS Code remained unpatched at publication. Contrast: the agent’s built-in browser is not a normal browser. Heat 4.
