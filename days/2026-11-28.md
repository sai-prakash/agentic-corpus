# 2026-11-28

**HoMe: evaluation-driven harness optimization for memory systems**. arXiv:2611.34624 (submitted 25 Nov 2026). The behavior of long-running assistant memory is governed by a harness of code, prompts, and configs for construction, maintenance, retrieval, and answer generation. Unrestricted editing does not guarantee structural gains. HoMe iteratively derives each candidate harness from any previously evaluated one, localizes shared failures via session-level memory versioning and execution traces, and gates early structural exploration. On the open-source ReMe system, six formal candidate evaluations improve end-task scores by 2.8 pp (LongMemEval-S) and 5.4 pp (BEAM-1M) while cutting query-time tokens 59% and 41%. Contrast: free-form manual harness edits are not the same as localized, evaluation-gated structural search with memory reuse. Heat 5. Paper + shipping plugin in agentscope-ai/ReMe.

**TASK Memory: text + activation steering + knowledge edit against use-time hallucinations**. arXiv:2611.34762 (25 Nov). Agents retrieve the right memory note yet ignore it, misapply it to the wrong entity, or confuse versions. TASK pairs a text note with a removable knowledge edit (shared in-model address) and a pair of content-free steering vectors that decide, query by query, whether to adopt the memory or keep the parametric answer. On frozen open models under a pre-registered protocol it drops memory-ignoring to ≤1.5% and neighbour misuse from 39.2% to 7.5%. Contrast: pure text-in-context memory is not sufficient when parametric knowledge conflicts with the retrieved note. Heat 4. Paper + independent X discussion of use-time memory failures.

**Pax / Pydantic AI Harness: everything is a plugin**. Official beta (25 Nov). Pax is a terminal coding agent built on the Harness SDK where the coding agent itself, sandboxes, MCP, Logfire tracing, and custom agents are all swappable plugins. You can point it at any Pydantic AI agent with `--agent`. In single Harness-Bench SWE81 runs it scored highest average among four full-model harnesses (58.5). Contrast: a fixed monolithic runtime is not the same as a capability-plugin surface that lets teams swap only the pieces they need. Heat 4. Shipping product + independent X posts.
