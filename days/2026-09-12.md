Ecdysis (2609.11677, Yue / Cui / Sun / Pan / Xue / Li / Li / Zhu / Chen / Liu / Huang / Cui / Zhang / Zuo, 10 Sep): a single failed run is not a harness bug. Distinguishes model-specific accommodation from systematic harness deficiency via batch-level cross-instance failure aggregation and Failure-Driven Collaborative Refinement. Up to 1.84× harness-training speedup vs prior evolution loops; resulting harnesses +18.56% reasoning accuracy; better transfer across LLMs; quarter-data match of full-data training (author + DAIR.AI 11 Sep). No public repo this window. Pair with HarnessEvolve / RobustSGPO: those gate the *diff* and the *permission to search*; this gates *which failures are allowed to request a diff*.

Mosaic (2609.11065, Lee / Oh / Kim / Lee / Song / Jang / Youn, 10 Sep): a shared GraphRAG walk is not a query plan. GraphRAG-Bench query-weighted Answer Correctness 76.97 Medical / 64.33 Novel (+5.13 / +4.43 vs prior overall reports). Medical Evidence Recall 95.1, Context Relevancy 86.1. Same graph+generator: no fixed narrow/medium/wide policy wins; Mosaic +9.96 over strongest canonical fixed policy; vs Fixed Wide evaluates 81.9% fewer paths and retains 47.2% fewer evidence items. Transfer interface on HotpotQA / MuSiQue / 2Wiki without benchmark-specific retriever training. No public repo this window. Pair with LiteRAG (2609.10239): that deletes query-time LLM control; this keeps an LLM only as the *policy writer*, not the walker.
