# 2026-11-04

ParetoSaddler (arXiv:2611.02079, 1 Nov 2026; X discussion by @omarsar0): harness optimization that jointly improves quality and cost by separating intermediate candidate promotion (Bayesian bootstrap Pareto support on either axis) from final deployment selection. On ClawMark quality 70.86% → 81.35% while cost $1.17 → $1.01; on GAIA2 56.22% → 62.89% while cost $0.78 → $0.45. Pareto-selected harnesses beat quality-only optimization on both axes. Contrast: joint quality-cost harness search is not quality-only search; promoting intermediates that are not yet deployment-preferred can unlock later gains. Heat 5. Paper + serious X thread.

Raw-RAG / naive dense retrieval over raw conversation history (arXiv:2610.30755, 22 Oct 2026; companion code Litmeb/RAW-RAG; The Frontier / Flowtivity writeups): ranks first among compared agentic memory systems in six of seven benchmark-model settings on LoCoMo, LongMemEval, MEME, MemoryAgentBench. Higher coverage of necessary evidence offsets lower utilization; transformed memory stores still leave an accuracy gap relative to raw evidence. Contrast: complex agentic memory (mutation, graphs, learned retrieval) is not always required for long-conversation tasks; naive RAG over untouched history is a strong baseline. Heat 4. Paper + code + articles.

StarNet (github.com/androoAGI/starnet, ~2k stars; local-first desktop multi-agent harness): pixel-art space station where rooms = capability-scoped teams, hallways = authorized handoff lanes, placed objects = real capability grants. Truthful telemetry: UI only shows what the harness can prove. Concurrent distinct agent runs with own workspace/memory/permissions, MCP, spend ledger. Contrast: spatial layout as the live permission and workflow model is not a skin over a chat + tool list. Heat 4. Shipping repo + X discussion.

Latent Harness (arXiv:2611.01415, 1 Nov 2026): compiles external harness behaviors into rank-8 post-block activation shifts on a frozen backbone (0.03-0.05% params). Recovered source-harness gains in 8/10 settings with no harness text/tokens at inference. Heat 3 (single paper so far).

CLEO (arXiv:2611.03434, 2 Nov 2026): method for fitting a minimal, auditable harness to a fixed self-hostable LLM. Reaches 83.8% pass rate within 1.2 points of Claude Code SDK baseline while two orders of magnitude smaller. Heat 3.
