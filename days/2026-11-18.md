# 2026-11-18

**Living Context Graphs (Continual semantic layer over enterprise data)**: arXiv:2611.20976 (Varun Agrawal et al. / Genloop, submitted 16 Nov 2026; accepted NeurIPS 2026 CL workshop). A no-copy context layer bootstraps semantics from the warehouse itself, indexes reusable business context in a concept graph as queries are served, writes durable learnings from verified outcomes, and withdraws context that later outcomes contradict. On a transfer-aware split of three BIRD databases (499 questions), learning from history only lifts held-out text-to-SQL accuracy +22.6 points over the untouched set, beating five-shot retrieval from the same history by +12.3 points. Contrast: a static schema or frozen few-shot set is not a layer that earns transfer by revising itself from use. Heat 4. Paper + OpenReview.

**ToolGraph as a Q-function (Test-time scaling for tool-use agents)**: arXiv:2611.20569 (Ke Shen et al., submitted 16 Nov 2026). Compiles a tool catalog once into a directed weighted dependency graph (parameter matching + interventional probes). Prior work retrieves or searches the graph; this work composes paths into a goal-conditioned action value Q(s,a,g). An LLM estimator that also reads concrete state beats personalized-PageRank over the identical graph by ~8.3 points on average across two benchmarks and three backbones; pure structural estimators do not, because type-level values cannot catch a correct tool called with wrong arguments. Contrast: graph-as-retrieval is not graph-as-multi-step-value that still sees arguments. Heat 4. Paper + OpenReview.

**Anatomy of an Agent Harness (Decisions, invariants, corner cases)**: arXiv:2611.19960 (Resham Joshi, submitted 15 Nov 2026). Writes the usually-implicit decisions inside a harness (request building, tool execution, permissions, storage, recovery, visibility) as 30 decision cards with invariants, corner cases, tests, and evidence tags, plus a checklist. Applied by the author to his own harness: 11 of 30 items hold, 14 do not. Contrast: rediscovering the same failure modes in every new codebase is not explicit invariants that can be tested with planted changes. Heat 4. Paper + discussion.

**Agentic GraphRAG on FalkorDB (Numbered evidence for agents)**: FalkorDB GraphRAG-SDK blog (updated 17 Nov 2026) + shipping repo and MCP server. An existing agent receives bounded tools over a knowledge graph; every piece of evidence returns numbered and checkable; the same agent can build the graph from a folder. Contrast: planning without receipts is not citation-checked graph evidence that can abstain. Heat 4. Shipping SDK + blog.
