# 2026-09-02

Cal Paterson, *Agent memory as a file format* (31 Aug; HN ~190; spec + CLI + skill shipping): memory is a data format, not a pipeline. Three failing species — vendor-harness lock-in that mines *you* instead of the world; pgvector+Neo4j+judge stacks that decide what is worth storing; High Modernist graphs that strip prose into isolated propositions. A memoryfield is a flat directory of short Markdown pages (soft cap ~8kb) with optional YAML frontmatter and an optional SQLite vector index. Retrieval is a semantic jump (search, then parallel read) — two tool calls, not N-hop graph walking. Contrast with yesterday's IBM structure-boundary and Graft: entity-centric markdown is the cheap map; a walkable ontology is inventory unless the reader actually traverses it. Paterson's extra claim: agent-written prose does not need the extraction mill you use on legacy PDFs.

MNIST-PRO (2608.31022, Toh / Majumder / Liu / Chen / Poria, 31 Aug): MNIST turned into a glimpse-based, lookback-constrained search so the experiment isolates perceptual-state construction. Three bottlenecks survive tool autonomy — agents fail to stitch glimpses, stop exploring before the sequence is seen, and keep early wrong identities against later evidence. Autonomous harness (Agentic MCP: files, code, tools) lifts Gemini-3.7-Flash Memory Canvas 68% → 88% on Level 1 and 38% → 63% on Level 2. Persistent memory does not: Gemini Agentic MCP 75.5% average → 73.5% with persistent memory → 74.5% with memory+feedback; GPT-5.6-Terra 31.0 → 32.0 → 28.0 on Level 1. The write-up is explicit: persistent memory transferred procedural instructions, not a persistent executable artifact. A diary of how you stitched last time is not a canvas you can reopen.

Warp / Anthropic (Claude blog 26 Aug, Warp docs still current 1 Sep): self-improvement is two skills and a gate. Inner skill does the job (issue triage, review). Human correction is the signal. Outer skill reads those corrections on a schedule and opens a small PR against the inner `SKILL.md`. Principles, not rule lists — rules overfit the last ticket. This is harness evolution with a human merge as the recoverability gate. Pair with EvoUndo: a skill diff that raises the last-run score is not admissible until a second state can be restored.

Experience graphs recirculated (AgentPatterns 2 Sep; EXG 2605.17721 May): wins and failures as a relational store — trajectory node, transition path, distilled insight — online growth during execution plus offline reuse. That is the opposite pole from memoryfield. Do not merge them. An experience graph needs trusted writers and a long deployment; a memoryfield needs portable pages and a deleteable index.
