# 2026-08-30

WikiSkill (2608.27454, Google Research / Virginia Tech, announced 27 Aug, circulating 29 Aug): skill evolution is not a growing pile of SKILL.md files. Three stores — raw traces, a persistent wiki of consolidated lessons, executable skills that cite the wiki. Gemini-3.5-Flash 49.5 → 68.1; Qwen-3.6-27B 39.4 → 63.3. Skills transfer across model families; a smaller model with evolved skills can beat a larger model without them. Ablation: drop the wiki and the loop collapses. Same contrast as Recuris/CaSKG — experience must be compiled, not replayed.

HarnessLens (2608.27311 + github.com/jhxu5214/HarnessLens): StarHarness-style propose-and-verify wastes rollouts when every candidate is scored on a fixed task set. Behavior-aware batches (conversion / positive-control / preservation / diagnostic) plus an attributable-evidence gate. +7.6–13.6 held-out across three harnesses and four benches, cheaper than full-set verify. This is the missing sensor on harness-evolution.

SARA (2608.27146): tool *output* that specifies an action is a command, not data. Action induction ≠ execution authorization. Context-isolated Action Probe records provenance; No-History-Promotion stops a past observation from laundering itself into authority. ASR ≤ 0.63% on AgentDojo / AgentDyn. Pairs with MHS: the kill-switch is outside the prompt.

AgentJudgeBench (2608.26623, EMNLP 2026): LLM-as-judge on tool-calling over workflow DAGs. Alignment falls with task difficulty 1.5× faster without gold; on hard queries without gold all six judges collapse to 77–82 regardless of scale. Ground truth can *hurt* GPT-5.4 / Gemini-2.5-Pro (over-anchor). Structured rubrics +6.5 pp, CoT and temperature ~0. BTS-AgentBench (2608.27334 + kjy7567/BTS-AgentBench) is the construction path: telemetry → read-only tool store → gold tasks → typed multi-turn episodes, two independent builds match exactly. Codex post-mortem (29 Aug, Tibo): MCP tool results encoded twice; memory workers inherited Stop hooks and looped 15k times. The eval gap and the production bug are the same object — unverified tool I/O.

Parametric KG memory (2608.25489, 26 Aug): LoRA-per-entity stores facts at zero query-time tokens. Storage works; similarity retrieval of the *right* adapter is chance. Graph memory that you cannot address is a write-only diary.
