Finding the Right Fit (2610.00917, Li / Zhou / Teng / Yang / Deng / Lyu / Dong / Chen / An, submitted 1 Oct + github.com/liyix/finding-the-right-fit): a strong model is not a strong pairing. Sixty-six configurations: OpenHands, DeepSeek Harness, PI, and openJiuwen with five models on TUA-Bench, ALE-CLI, and Terminal-Bench 4, plus native Codex-GPT and Claude Code-Claude. On Terminal-Bench 4, Claude leads GPT by 7.94 points in OpenHands and trails it by 30.16 points in PI. For four of five models the best harness changes by benchmark; openJiuwen is Kimi's best on all three, by 5.61 to 11.11 points. A vendor harness is not reliably best, and higher cost is not a higher score: on Terminal-Bench 4, GPT scores higher under PI than under DSH at less than a quarter of the cost per task. Models start almost all repairs themselves; the cage has to hand the failure back in a form that model can use. GPT prefers PI's lean scaffold; Kimi, which often emits malformed tool calls, prefers openJiuwen. Adapters, eval code, and 6,204 scored trajectories are released. Heat 5 under agent-harness / evals-gates. Pair with thin MLE (2609.40303): that paper held the backbone fixed and found the elaborate cage redundant. This paper moves both and finds the ranking is the pairing.

Mingbird (2610.02001, Hao Wang / Ting Huang, submitted 1 Oct + github.com/Mingbird/Mingbird-agent): a cloud harness is not a laptop harness. Small open models (2–9B) under cloud-scale cages overflow prefill, diverge on self-correction, loop on tool demos, and abandon tasks. Mingbird is a local-first Windows/Ollama harness: byte-level net-zero prefill, a finish gate that re-reads the task before accepting completion, and signature-level loop detection. LRAB holds machine, models, budgets, and scoring fixed (4 harnesses × 4 open models 2B–35B × 18 real tasks): Mingbird 0.886 vs goose 0.631, opencode 0.479, agent-mini 0.405; all 288 cells published. τ²-bench 278 tasks: 0.856 vs 0.791 and 0.737. A frontier probe on the same 18 tasks spans 0.997 to 0.478 across harnesses; well-formed scaffolds stay within 0.072. Leave-one-out is directional only: same-night replications move a mean by up to 0.069, the size of every nominal single-trial delta; the batch-matched completion-guard comparison is a paired +0.10 across three replications. Self-built bench, one machine, single-trial scoring. Heat 4 under agent-harness. Pair with Finding the Right Fit: one measures rank reversal on frontier pairings; the other measures cage-attributable failure on small open models. Do not read 0.886 as a portable SOTA.

Global Coherence (2610.02036, Xin Heng, submitted 1 Oct): a locally valid act is not a coherent team. Observation-Aliasing Impossibility: a policy can guarantee a valid action only when every world that produces the same observation shares an admissible action. If k indistinguishable worlds need pairwise-disjoint actions, best randomized worst-case success is 1/k; more reasoning, roles, messages, or samples do not recover the missing distinction. Runtime semantics X = (H, C, G, F; D): topology, state-changing actions, reversible translations, a sheaf that tests whether local views glue, and a minimal history of distinctions that alter legal futures. Models propose; the harness owns shared state and governs commit. Controlled revision: same frontier model 40/40 when the deciding event is visible, 12–17/40 when hidden (chance is 1/3), 40/40 when one authoritative fact is restored. TeamBench: ordinary teams exceed a shared budget in 5/5 runs; a visible live count leaves 4/5 violations; commit enforcement leaves 0/5. tau2-bench Telecom: current-state checks score 0.07 after silent reverts; the harness scores 1.00. Where a conventional solver already owns the complete relevant state, it ties the harness. No code URL in the abstract. Heat 5 under evals-gates. Pair with MAS mechanism diagnosis (2609.38761): a right answer is not an intact mechanism, and a right local act is not a glued world.

Agents Are Systems, Not Models (2610.01618, Wiedmann / Girrbach / Schmid / Akata, submitted 1 Oct): a success rate is not an agent. Users choose what to tell it, how long to let it run, and which model to use. Four scientific tasks where a coding agent must find and operate a published specialist model. Five configuration axes: task information, reasoning, self-verification, time budget, backbone. About 54% of outcome variance comes from repeating the same configuration, not from changing it. Information has the largest effect, ahead of time budget and model size, and also cuts cost and improves calibration. Extra time helps only with enough information or a capable enough model. Prompting the agent to verify barely changes verification behavior; a dedicated verification tool changes it substantially. Benchmark and more than 18,000 trajectories released; no URL on the abs page, so do not invent a repo. Heat 4 under evals-gates. Pair with Finding the Right Fit: one swaps cages, the other shows the rerun is already half the variance.

Causal Memory Policy (2610.02070, Behnam / Wang, submitted 1 Oct + anonymous.4open.science/r/cmp-release-D0C3): a store-level utility estimate is not an identified utility. If a memory is never retrieved, store interventions produce identical outcomes. That is a retrieval-level positivity violation, invisible to diagnostics that only watch memory operations. CMP reserves a fixed number of context slots for memories sampled with known propensities and estimates utility by self-normalized inverse propensity weighting. Identification fails for 54% of required memories on LongMemEval and 67% on LoCoMo, and the failure persists in a deployed memory system. Discrimination of required vs non-required memories moves from 0.54 to 0.66 AUC. Identified utility is still not a retention policy: per-query utility reaches 0.78 AUC on the query it was estimated for. Heat 4 under memory-lifecycle. Pair with TRACE (2609.33517): one refuses stale return; the other refuses to score a memory the retriever never showed.

Meta-Skill (2609.38143v2, Qian / Zhu / Li / Wang / Ji, submitted 29 Sep, revised 1 Oct): handing the bank to the target is not a builder that learned when to spend it. Weights stay frozen. A Builder learns principles — when support is needed, what resources to provide — from the Target's development-set feedback, then uses the frozen skill bank to construct harnesses for unseen tasks. Harness-Bench and NewtonBench: full-bank meta-skills +8.95 percentage points macro-average over no-skill construction, and +12.02 over direct delivery of the same bank to the Target. Same-model dual role is reported as a self-improvement path, not a weight update. No code URL. Heat 4 under skill-memory / harness-evolution. Pair with EngramBench's last-mile claim from 30 Sep only as a hold: a skill bank is a compass, not a substitute for the builder that decides when to open it.

ReCAP (2609.40118, submitted 30 Sep, submitter Jingbo Yang; coauthors not named on the abs history line): a summarization compact is not a persistent dependency graph. Attention-derived importance and message dependency links sit in a lightweight context graph. A new request combines stored importance with request relevance and walks dependency links, with no extra model call for selection. Versus Codex default summarization, estimated latency for compaction and cold restoration drops by about 95% on Qwen3-Coder and gpt-oss. Historical context per call on SWE-Together is roughly halved at comparable task quality. Lost-in-Conversation code tasks improve over full history by 19.8 and 41.2 points. No code URL on the abs page. Heat 4 under memory-graphs. Pair with CLM (2609.37725): one lets the model edit a context file; the other selects supporting messages from a stored attention graph. Do not read the 95% line as a quality lift.
