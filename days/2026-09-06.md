ClaimReceipt (2609.01992, Zhu / Chang, Blossom AI, 2 Sep; NeurIPS 2026 "Who Verifies the Agents?" workshop track): a log is not an eval. Sufficiency asks whether a reported claim is recomputable from retained evidence. Coverage asks whether the retained records cover the committed experiment set. Generic transcripts and hash chains answer neither. ClaimReceipt binds typed transaction evidence to a signed experiment manifest and returns PASS / INVALID / INCONCLUSIVE per claim. Spec frozen before implementation (SHA-256 18d109…b81). On 1,392 historical buyer–seller records, a CR-2 verifier reproduces five manual audit verdicts, replays 600 deterministic + 792 post-generation records, and catches 11/11 semantic faults with 0/8 false positives. Prospective CR-3: 30 assignments committed before inference; withhold one terminal receipt → INCONCLUSIVE_COVERAGE; withhold private openings → coverage still passes, economic claims do not. Missing evidence must not become a green cell.

ToolGate (2609.02067, Zhang / Liu / Zandi / Raissi, 2 Sep): scientific items whose answers require specialist software are not accepted by peer review of the prompt. Three gates: an executable script must reproduce the proposed answer in the tool; randomized no-tool screens drop items a model already solves from the prompt; a tool-using agent must solve the survivor in a time box. FEniCSx instantiation: 500 generation attempts → 478 local-verification keepers → two no-tool screens drop 222 → GPT-5.5 API medium drops 121 → 135 remain → GPT-5.5 Codex CLI + FEniCSx solves 130 → 128 unique protocol survivors. Domain design stays with experts; acceptance becomes an audit trail. Pair with SWE-Gate: one compiles review comments into a second suite; this compiles "needs the tool" into a generation filter.

RealSWE (2608.27831, Kim / Gwon / Kim / Shim / Lee, SKKU, 28 Aug v2 31 Aug; HF daily 4 Sep; github.com/gyuhyeong-x/RealSWE): SWE-bench issues are long, structured, and information-rich. Real prompts from SWE-chat are not. Problem-statement-only (or nearly) is 88% of real prompts and 7% of bench problems; 87% of real prompts are casual, 94% of bench problems formal. RealSWE builds 381 multi-variant families from Verified and Pro that share gold patch and vary only information composition and style. Seven models: realistic inputs drop resolution 6.4 pp on average and can reorder rankings. Desired Behavior and Motivation move the score; Environment Information and Reproduction Steps add tokens without a measured lift; style effects are small and model-dependent. The eval harness is not yet public. A green number on a padded issue is not the same object as a green number on a one-line ask.

BCIT (2608.26730, Li / Feng / Li / Wuerkaixi / Liu / Zhang, Alibaba Cloud, 27 Aug; HF 4 Sep): a past post-training win is not a license to mutate the current parent. 13 of 24 candidate–context pairs failed to improve the target when reused naively. Boundary-Calibrated Intervention Transfer binds the observed effect to source context, vetoes named hard conflicts, and runs a bounded trial on the current parent before weight-changing work. Harmful authorization 62.5% → 25.0%; equal-budget mean +2.63 over Flat-Additive (95% CI 2.10–3.16). A 20% budget probe recovered direction on 20/24. Treat as authors' report on one 4B model. The contrast that ships: reuse is a gate, not a default.
