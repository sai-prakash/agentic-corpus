# 2026-09-07

PlanFence (2609.03340, Chen / Wang / Brinton, Purdue + Exeter, 3 Sep): a fresh replica is not a valid plan. Distributed teams can hold the latest shared fact and still execute an action derived from an earlier record. Planner reads requirement r3 and writes p(r3); another agent commits r4; the executor can receive r4 and still call tools from p(r3). Freshness-only execution did that in 30/30 controlled live workflows with a post-plan revision. PlanFence makes the plan cite the public records it used and validates only the records that can change the pending external action — replan once or block. Same 30 tasks: zero invalid actions. Replay: proactive sync wins at low churn; PlanFence wins as churn and keyspace grow because it does not re-walk the whole store. Authors mark this as safety and systems cost, not a task-accuracy lift. Pair with ClaimReceipt: missing evidence is inconclusive; stale lineage is a block.

Gated-Memory Routing (2609.00237, Rajib / Zheng / Lou, UCF, 31 Aug; EMNLP 2026 Main; github.com/rajibrhasan/gated-memory-routing): routing on the query cannot see mid-run error; routing on the raw transcript pays for every prior step. A Memory Write Gate commits only non-redundant reasoning; a Retrieval Gate hands each agent a compact slice; an Adaptive Halting Controller stops when that memory already contains enough evidence. Five reasoning and code benches: best average accuracy, +2.44 over the strongest baseline; HumanEval cost −31.9% vs that baseline (0.068 → 0.032). Query-only MASRouter is the least accurate of the three routing regimes they report. The object is execution memory, not a second knowledge graph.

MASkills (2609.02094, Yao / Liu / Fleming / Chen / Wei, ASU + Cisco Research + UNC, 2 Sep; EMNLP 2026 Findings; github.com/DaRL-GenAI/MASkills): a reflection dump is not a skill. Self-reflection stores experience that is hard to invoke, credit, or retire. MASkills keeps a library of `SKILL.md` files and applies typed operators — refine, induce, consolidate, prune — under skill-conditioned credit (central critic, counterfactual on the invoked skills only) plus a held-out gate that rolls the library back if the candidate does not hold. HotpotQA F1 76.3 vs MultiPersona 69.2 / Self-Refine 60.8. LoCoMo SH-F1 27.61 vs MemGPT 26.65 and LoCoMo 25.02. GAIA average 23.3 vs Vanilla ReAct 18.4; L3 stays 0.0 while R1-Searcher reports 8.3 — do not overclaim the hard split. The contrast that ships: credit the skill the trajectory actually called; merge is the gate.

GitLab Orbit (about.gitlab.com/blog/introducing-gitlab-orbit, docs updated 6 Sep; github.com/gitlabhq/orbit-knowledge-graph): a context graph that is a product still has to name what it is *not*. Orbit indexes SDLC objects and source into one property graph and serves it over MCP / glab / REST. Compare the Market, 79 real merge requests: Orbit-grounded reviewer ~70% accurate inline comments vs ~58% RAG; RAG underperformed no-context. GitLab CEO Bill Staples (clip recirculated 5–7 Sep): beta since June, >2,200 orgs (+70% in four weeks), >170k queries, ~80% of query volume from external agents (Claude Code, Codex). That is a live context graph consumed by other harnesses. It is not memory, not a plan fence, and not proof that graph walking beats two-call retrieval in the small-lab case. Pair with Graft: repo-local markdown map vs hosted SDLC graph.
