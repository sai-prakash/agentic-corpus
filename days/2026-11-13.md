# 2026-11-13

**FGSE (Falsification-Gated Self-Evolution)**: When Should Agents Remember? (arXiv:2611.14326, Runxuan Tang et al., submitted ~10 Nov 2026): current self-improvement writes episode-derived lessons directly into memory, treating local success as reusable knowledge. FGSE represents each candidate lesson as a structured hypothesis (precondition, behavior change, expected effect, verifier), applies it only in temporary state, and tests on target-transfer, falsification, and archived-regression probes before commit/refine/reject. On WebArena 39.8% success, AppWorld 78.8% avg completion, τ-Retail/Airline Pass¹ 0.724/0.487; falsification failures 5.0%, regression damage 1.3%, harmful commits 3.6%. Contrast: direct memory write is not hypothesis testing under verifier probes. Heat 4. Paper + research digest mentions.

**WikiTrace (Evidence-Linked Memory)**: Don't Just Trust Your Memory (arXiv:2611.14320, Yukyeong Lee et al., submitted ~10 Nov 2026): memory can induce degradation when agents follow incorrect or misapplied lessons that lack the original trajectory for checking. WikiTrace stores each lesson as a concise insight linked to a summary of why its trajectory succeeded/failed and to the raw trajectory; on new tasks the agent descends the links with terminal tools when details are missing, conflicting, or from failed tasks. Contrast: free-floating lessons are not evidence-linked and checkable. Heat 4. Paper.

**SparseRead**: Read Less, Solve More (arXiv:2608.22237v2, Zedong Liu et al., revised 7 Nov 2026): agents over-read full artifacts when only sparse evidence is needed. SparseRead is a training-free reading control layer with Read Intent Protocol, Adaptive Reader Backends, and Budgeted Read Gate that admits only needed evidence before it enters context, with full-view fallback. Across six models (incl. Claude Opus 5) and five scenarios, up to 92.9% token and 89% wall-time reduction while preserving/improving quality in 97% settings; portable across NanoBot, OpenCode, OpenClaw. Contrast: naive full read is not gated admission of sparse evidence. Heat 4. Paper + public repo + project site + X discussion.
