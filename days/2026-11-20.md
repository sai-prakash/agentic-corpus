# 2026-11-20

**GraphRAG Zero (Embedding geometry replaces LLM indexing for interactive graph retrieval)**: Microsoft Research story (17 Nov 2026). Eliminates LLM calls at index time and can skip them at query time, delivering sub-second retrieval via text embedding geometry. Ships in Foundry IQ (Azure AI Search) and GitHub’s Repo Mind Light for repository understanding with agents. Contrast: original GraphRAG’s LLM-heavy community summarization is not zero-call embedding-guided retrieval that stays interactive. Heat 5. MS blog + product integrations + high-engagement X from @MSFTResearch.

**Semantic Context Handoff (State carries interpretation; evidence archive re-enters on demand)**: arXiv:2611.24357 (Guolong Zheng et al., submitted 18 Nov 2026). Compact semantic state holds current interpretation while action-observation evidence stays addressable and re-enters context when later execution makes it relevant, without separate summarization or retrieval calls. On 150 SWE-bench tasks, evidence recovery lifts Pass@1 from 80.0% to 86.9% at near-identical token/time cost; full system uses 43% fewer tokens than strongest baseline. Contrast: full-history prompting is not state–evidence separation with on-demand recovery. Heat 4. Paper + X discussion.

**Self-Improvement Memory (Optimizer diary of edits enables continued recursive improvement)**: arXiv:2611.18856 (Xin Yu et al. / Google, submitted 13 Nov 2026). Self-Improvement Memory groups harness edits by problem, records rationale, predicted vs observed outcome, and eval context so the optimizer can reuse/revise when benchmark or policy model changes. Across domains, SIM beats harness-only continuation; on coding, +2.36 points average (p=0.003) over 10 paired runs. Contrast: evolving the harness code alone is not carrying the experience of why each edit was made. Heat 4. Paper + X + coverage.

**Warrant-preserving skills (Reuse claims need admissible evidence after context change)**: arXiv:2611.23990 (Nami Cho, Shailja Gupta, submitted 18 Nov 2026). A skill that executed yesterday may not be justified for reuse today; proposes Warranted Reuse Claim and Warrant-Preserving Evidence Transport. Formal problem statement and design obligations, no empirical verifier yet. Heat 3 (signal). Single paper.
