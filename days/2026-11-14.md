# 2026-11-14

**DISCERN (Preserve at Write, Resolve at Read)**: Persistent LLM-Agent Memory (arXiv:2611.15729, Chirag Ahuja, Vladislav Tanov, Ramcharan Kakarla, Jonathan Taws, submitted 11 Nov 2026): enterprise agents accumulate contradictions and entity collisions; the field treats memory as a retrieval problem, but recall pillars (retention/currency) are already near-saturated at 0.93–0.98 with vanilla RAG. What remains is resolution—entity disambiguation, current time-state, and whether to answer or abstain. DISCERN builds a strictly additive bi-temporal provenance graph at write time that never merges confusable entities and never drops superseded values; at read time a zero-LLM tool surface drives an agentic loop that navigates the graph and commits exactly one of four gated terminal actions. On ENT-310 (310 queries): best abstention F1 0.924 (vs ≤0.802 for eight baselines), macro answer correctness 0.861 (vs 0.806), entity resolution 0.800 (vs ≤0.40); zero-tuning lead on full LoCoMo as well. Contrast: resolving or merging at write is not preserve-then-governed-resolve. Heat 4. Paper + HTML version.

**AI-RAN Context Graph**: Explainable Multi-Agent Decision Chains (arXiv:2611.16879, Xijun Wang, Zhaoyang Liu, Xiang Chen, Howard H. Yang, Chenyuan Feng, submitted 12 Nov 2026): AI-RAN distributes control across autonomous xApps and rApps; operators lack a structured way to trace which decision caused an alert, what context triggered it, and how agents interacted. Existing tools stop at single-model attribution or linear logs. The Context Graph is a heterogeneous directed graph whose foundational primitive is the Decision-Event node acting as a causal junction: incoming edges capture triggering context, outgoing edges track downstream consequences that are progressively upgraded through counterfactual verification. Instantiated over E2/A1/O1 flows, compliance and diagnosis queries resolve at sub-millisecond latency over graphs of tens of thousands of nodes and distinguish true causal impacts from spurious correlations. Contrast: linear event logs are not cross-agent causal junctions with counterfactual upgrade. Heat 4. Paper.

**Harness Memory Protocol**: Cross-harness shared long-term memory (HarnessRouter Community Edition, Apache-2.0, Unified Harness Protocol Memories chapter; memory defaults and protocol updates ~9–12 Nov 2026): memory is a tree of records with per-node grants, independent of any single harness session. Agents running on Codex, Claude Code, Hermes, etc. can recall and write the same memory store. Open-source implementation plus X announcements of the protocol launch and Product Hunt feature. Contrast: per-harness siloed memory is not protocolized, grant-controlled shared memory. Heat 4. Shipping repo + X discussion.
