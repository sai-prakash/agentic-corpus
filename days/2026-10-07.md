HEAR (2610.06597, Jiaqi Zhao / Haodong Chen / Jitai Hao / Wei Zhao / Jinghao Pang / Qiang Huang / Jun Yu, submitted 5 Oct; recap @KostyaAI status 2107382706937921978 on 6 Oct): an engine ack is not a completed control. The harness sees workflow dependencies, context lifecycles, and execution objectives. The inference engine sees queues, KV-cache state, resource pressure, and capabilities. HEAR is a bidirectional Harness–Engine pairing protocol: the harness sends intent and requirements, the engine returns runtime state and outcomes, and protocol semantics stay separate from the optimization policy. A preference is not a requirement. A state observation does not reserve resources. "Accepted" does not mean "completed." On SCBench under memory-constrained concurrent serving, cache-aware coordination raises batch throughput 1.61× and cuts median time-to-first-token 2.23×. Workload-specific role configs yield 1.23× on BrowseComp-Plus and 2.45× on DeepResearchBench, with no observed task-quality drop. Mooncake is the ablation that workflow intent and live engine state are complementary across load. No code URL on the abs page. Heat 5 under hear-protocol.

SquidAgent (2610.08647, Yexiong Lin / Shanshan Ye / Yu Yao / Zhen Fang / Bo Han / Tongliang Liu, submitted 6 Oct): forking workers is not a speedup. Parallel multi-agent runs often lose to a serial agent because of re-exploration (workers rebuild context the orchestrator already has) and alignment (reconciling independent outputs). A layer is worth parallelizing only when critical-path cost plus those two overheads beats the serial cost. LLMs estimate output tokens more reliably than wall-clock, so the criterion is token budgets from one planning step. Workers fork from the orchestrator session. A pre-generated shared convention block replaces post-hoc reconciliation. A deterministic scheduler applies the criterion per layer. Mean throughput is 2.2× Claude Code and wall-time 2.6×; throughput is 2.0× the strongest multi-agent baseline. The abstract does not name that baseline or print accuracy. No code URL. Heat 4 under agent-harness. Not a concept file: one paper, no second source in the window.

Agentic AutoRAG (2610.08452, Lasse B. Strand / Robert Jakob / Kevin O'Sullivan / Markus Kreft, submitted 6 Oct): an aggregate exam score is not a diagnosis. After each trial a Diagnoser attributes each failed question to retrieval or generation. A Proposer, grounded in model rankings and pricing, picks the next chunking / embedding / rerank / generation config and traces a Pareto frontier. On three multi-hop QA benchmarks it beats the compared baselines on LLM-judge accuracy, and its first 10 trials match or beat the statistical baselines' full 30-trial judge accuracy. On a healthcare corpus, cost-aware mode reaches median exam accuracy 77% versus the strongest baseline's 71.5%, at about 58% of that baseline's cost per query, and matches 71.5% at about 22% of the cost. The abstract does not name the baselines. No code URL. Heat 4 under evals-gates. One paper. Do not read 77% as a new retriever.

AdvSim2Real (2610.08773, Sarim Hashmi / Mukul Ranjan / Kshitij Mishra / Mikhail Kuznetsov / Praneeth Vepakomma / Nils Lukas, submitted 6 Oct): a fixed injection set is not a defense. The page holds both the task and the planted instruction. AdvSim2Real co-evolves a task curriculum, an injection adversary, and the agent inside a frozen web world model. The curriculum is rewarded for tasks the agent solves about half the time. The adversary is rewarded only for a success flip. On 150 web tasks, a 4B agent raises completion under an unseen frontier-model adversary by 33.6% relative to the base agent. Capability gain carries to a real browser. The abstract does not print the absolute completion rates. No code URL. Heat 4 under harness-evolution. Pair with VeriFine below: one co-evolves the attacker, the other co-evolves the judge. Not a concept file.

Memory depth vs width (2610.08300, Michael Andreev, submitted 6 Oct): a deeper memory tree is not a wider reconstructed context. On EverMemBench, depths D1–D4, core budgets 1,024 / 2,048 / 4,096 tokens, plus Production and Oracle up to the full archive. Width from 1K to 4K raises Accuracy 10.11–17.98 points. Depth has no monotonic gain. Past 8–16K, Production plateaus while tokens per correct answer keep rising. Oracle holds quality on full archives of 68–71K tokens. No code URL. Heat 4 under memory-lifecycle. Contrast with memory-graphs: hierarchy without a width budget is the failure mode this paper measures. One paper, so no concept file.

Causal Improvement Graph (2610.05039, Junjie Zhang / Shunyu Liu / Haoyu Wang / Ting-En Lin / Yongbin Li / Dacheng Tao, NTU and Tongyi Lab, Alibaba, submitted 4 Oct; HTML on 6 Oct): a proposer prompt is not an improvement state. CIG externalizes harness search as a persistent graph of Evidence, Hypothesis, Intervention, and Outcome nodes, so a local proposer reads relations instead of reconstructing the experimental logic from raw history. The abstract says CIG finds stronger harnesses than prior meta-harness baselines and is robust to solver and proposer choice. Structural ablations support the explicit graph. It does not print the deltas or the task list. No code URL. Heat 4 under causal-improvement-graph. Second source in the window is Harness Learning (2609.35738), the proposer-centric loop this graph is built to replace. Pair with Ansatz (2610.02945): that graph stores the counterexample; this one stores the intervention that was tried.

SHIFT (2610.04137, Som Sagar / Shasha Li / Hejie Cui / Ransalu Senanayake / Sercan Ö. Arık, submitted 2 Oct; catch-up, not in the 6 Oct file): executing alternatives at inference time is not a predicted harness. A local architect learns a policy over harness-building actions; a value function predicts utility from measured executions; Monte Carlo tree search builds a harness per query. Across 9,193 tasks in six benchmarks with a Gemini 3.5 Flash executor, mean accuracy is about 80%, 7.2 points over the strongest of 17 baselines. A cheaper mode beats every baseline at 32% fewer execution tokens. Joint choice of structure, instructions, and tools beats instructions-only or tools-only by up to 9.1 points. No code URL. Heat 5 under per-query-harness. Second source: STITCH (2609.38912, submitted 30 Sep) compiles mined primitives into a task harness at test time, up to 12 points over fixed harnesses, 2.7% composition overhead, 638× cheaper than generating harness code from scratch. SHIFT searches; STITCH stitches. Do not read 80% as a new base model.
