# 2026-11-01

KARMA training-free knowledge-atomic harness evolution (arXiv:2610.39884, Miao, Rong et al., Alibaba; submitted 29 Oct): evolves six typed knowledge modules via Trace Verifier + Critic on success/failure trajectories while freezing model weights and executable harness code. Atomic edits pass a regression gate or roll back. On ~0.5M real e-commerce logs across 6 domains and 3 LLM families, hold-out score rises 30.19 → 39.15 (+29.7%); knowledge transfers cross-domain (+8.54 avg). Contrast: knowledge evolution with frozen harness is not weight update or code mutation. Heat 4. Paper (signal; pairs with prior harness-evolution work).

Prefix executability for tool-using agents (arXiv:2610.40444, Rezaeian, Sun, Benajiba, Roth; submitted 29 Oct): trajectory-level protocol measuring whether every prefix of tool-call sequence remains executable under schemas, state preconditions, and data dependencies. Metrics: PEC curves, FED, TER, AUC-PEC, RR. On BFCL-v3, ToolSandbox, τ³-bench, outcome-only rankings diverge from prefix reliability; plan-conditioned agents can show higher final success with lower TER. Pairs with Executable Prefix Values (arXiv:2610.17633, 13 Oct) which locates failure causes via restart value curves. Contrast: final success is not trajectory executability. Heat 4. Two papers.

Long-term agent memory via complementary curation and consolidation (arXiv:2610.39790, Gupta, Han et al., Microsoft; submitted 29 Oct): hybrid of episodic memories + structured relational memories with consolidation. On LoCoMo 90.2% and LongMemEval-S 85.5%, outperforming SOTA. Complements Databricks MemCurrent / Agent Memory (blog 20 Oct, X 30 Oct): episodic + derived memory with offline "dreaming" pipeline triples internal enterprise pass rate 22.3% → 68.4% while cutting tokens 31%. Contrast: complementary hybrid is not pure episodic or pure derived. Heat 5. Paper + shipping product.

Value-indexed memory: retrieval as persistent local traversal (arXiv:2610.40545, Strauß, Bing, Knoll; submitted 30 Oct): separates content from address; cost-regularised indexing keeps complementary memories co-retrievable while excluding redundant ones. Fixed-geometry proof-of-principle on MiniGrid Memory learns faster than absolute addressing. Contrast: stateful local traversal is not global search or recurrent compression. Heat 4. Paper.

EvoTeam multi-agent collaboration via evolving teams (arXiv:2610.39813, Cao, He et al.; submitted 30 Oct): jointly evolves team organization, interaction rules, and individual skills from execution experience; maintains library of reusable teams with team-specific rules so collaboration experience stays in compatible contexts. Contrast: evolving the team is not only evolving individual agents. Heat 4. Paper.

Skill-centred agent for clinical genomics (ClinGeX, arXiv:2610.40556, Zheng et al.; submitted 30 Oct): composes 105 curated executable skills via task-specific retrieval and dependency-aware orchestration. 71.7% macro concordance vs 45.7% strongest comparator on held-out cases; human-AI study shows gains in concordance and reduced time. Contrast: skill composition is not end-to-end prompting. Heat 4. Paper.
