# 2026-11-17

**ModHarness-RL (Learnable evolving harness programs for agentic RL)**: arXiv:2611.18533 (Zelin He et al., submitted 13 Nov 2026): most agentic RL trains under a fixed hand-written harness. ModHarness-RL records interaction as typed State blocks and treats two harness components as programs over those blocks — a Compression program that assembles history into context, and a Steering program that supplies guidance on deviation. Candidates are proposed from recent trajectories, verified by execution, and replayed over past trajectories so the harness tracks behavioral shift. On CodeSearch it improves 14–24% over fixed-harness baselines and leads memory/skill/prompt/harness-evolution baselines by 5–12%. Contrast: a static hand-written harness is not programs learned from data that evolve with the model. Heat 4. Paper + HTML.

**Neural Context Protocol (NCP) (Bounded multi-agent memory bus over MCP)**: Shipping repo kulkarni2u/neural-context-protocol (recent activity ~16 Nov 2026, PyPI neural-context-protocol): MCP standardized agent-to-tool; NCP standardizes agent-to-agent. One MCP endpoint serves as a memory bus — agents read bounded, trust-weighted context, write durable memory, and emit directed whispers without replaying full transcripts. Local SQLite or pgvector+Redis backends. Reports ~13× fewer tokens than raw replay and ~1.44× fewer than sliding window on a 4-agent coding benchmark. Contrast: stuffing full transcripts or provider-native memory is not an explicit shared, trust-weighted, bounded bus that works across hosts. Heat 4. Shipping repo + protocol description.

**VaaT / Vision-as-a-Tool (Visual harness via callable MLLMs)**: arXiv:2611.17797 (Haolin Yang et al., submitted 13 Nov 2026, project page vision-as-a-tool.github.io): current multimodal coding agents rely on Thinking-with-Images (intrinsic vision). VaaT reframes general-purpose MLLMs as callable external utilities. Text-only agents can fully offload visual reasoning; vision-capable agents can augment native perception on demand. Instantiated as VHarness with five atomic actions; improves fidelity and geometric accuracy on Image-to-HTML, Image-to-SVG, and Image-to-3D. Contrast: visual reasoning locked inside the agent is not modular callable utilities. Heat 4. Paper + project page.
