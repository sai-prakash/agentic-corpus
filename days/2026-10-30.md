# 2026-10-30

Microsoft Copilot harness (official blogs 28 Oct by Tina Schuchman / Vladimir Fedorov; SDK at github/copilot-sdk now rebranded): the GitHub-built multi-model agent runtime is now the shared Microsoft Copilot harness, available as a managed Foundry Agent Service preview and downloadable SDK. It powers Copilot Code, Studio, the app, CLI and VS Code; supports MCP, skills and plugins; routes across 20+ models or BYOK. Internal evals: changing harness beat changing model (+10.8 / +22.1 pp pass rate vs Standard); tool-failure recovery 84–91% continued vs <7% on Standard, with >7× later successful retry. Contrast: the harness is the durable multi-model execution system, not the model. Heat 5. Product + SDK + discourse.

OpenWiki evidence-graph memory (LangChain blog 28 Oct by Eugene Liu; repo langchain-ai/openwiki): a compiled, cited wiki acts as durable domain memory; typed evidence-graph edges (claims → paragraphs, supersedes, etc.) let the agent locate and expand along structure instead of rediscovering. On 111 synthetic insurance docs / 972 facts: wiki alone ~5× more accurate than grep/search on connected questions; +graph doubles citation consistency, +27% accuracy, –58% cost per correct answer. Graph built deterministically in <1 s, no extra LLM. Contrast: persistent structured memory is not pure retrieval. Heat 4. Blog + shipping repo.

Hierarchical Skill Evolution (arXiv:2610.35616, Gao et al., submitted 26 Oct; code jungao1106/SKILL_EVO): progressively distills transferable procedural skills from coding trajectories—task-level evidence → repository-specific candidates → cross-repository skills—via an external writer-evaluator loop that keeps the coding model frozen. Ten skills evolved only on SWE-Gym improve pass rates on SWE-bench Verified and DeepSWE across GLM-5.2 (Pi and Claude Code harnesses), GPT-5.5 and Opus 4.8. Contrast: hierarchical aggregation yields transferable skills, not flat task-specific notes. Heat 4. Paper + repo.
