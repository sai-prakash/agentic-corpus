# 2026-11-08

MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents (arXiv:2611.07689, Yizhen Jiang et al., submitted 5 Nov 2026): existing MCP benchmarks measure task completion and diagnose after the fact. MCPHallu builds structural triggers into 358 tasks across five domains on 36 production MCP servers (isolated containers) so one of four subtypes dominates: Branch Collapse, Unreachable Goal, Tool Misuse, or Context Forgetting. Fourteen frontier agents, 5,012 trajectories: mean score 0.642; Unreachable Goal drops to 0.458 (23.2% pass) because agents keep calling tools or claim completion instead of recognizing infeasibility. Model ranks shift ~6.9 positions across subtypes; Branch Collapse uncorrelated with Unreachable Goal (r = −0.12). Contrast: aggregate task success is not a diagnosis of reasoning, execution, or memory failure modes. Heat 4. Paper + discussion.

MEMOIR: A Training-Free Memory Lifecycle for Long-Horizon LLM Agents (arXiv:2611.07631, Mayank Anand et al., submitted 5 Nov 2026): existing systems write memories prospectively with static importance that is never revised. This couples two failures—consolidation can destroy evidence later needed, and retrieval keeps favoring stale items. MEMOIR unifies judge-gated consolidation (screen that answer-relevant evidence is preserved before merge) with retrospective attribution (after each query, credit the memories that supported the answer and update priority) plus a UCB exploration bonus for under-exposed items. On 1,905 deduplicated LoCoMo QA pairs: +11.92 pp evidence recall@5 over bare cosine; confidence-gated feedback adds +1.50 without references or reranker training. Judge-gated merges: text-evidence recall 58.82%→59.08%, active store −1.42%, 0 observed losses in 100 audited merges (95% upper bound 2.95%). Contrast: static prospective importance is not retrospective attribution plus preservation screening before compression. Heat 4. Paper.
