# 2026-11-09

HEELO: The Last Mile to the Real World: Agent-Native Primitives as Reusable Building Blocks for Solving Real-World Tasks (arXiv:2611.07461, Haibo Jin et al., submitted 5 Nov 2026): frontier models with their own harnesses still fail at the step from reaching a resource to applying it. On Terminal-Bench 4.0, GPT-5.6 Sol with Codex resolves 37.3% and Claude Opus 5 with Claude Code 51.8%. The paper introduces agent-native primitives—reusable units that equip a resource with a resident LLM which applies it in context and communicates requirements or information to other primitives—and HEELO, a harness engineering framework that selects and composes the primitives a task needs into a task-specific graph, verifies the result against environment evidence, revises only the implicated primitives, and admits improved ones after validation. Dev-Primitives raise Terminal-Bench 4.0 resolution from 37.3% to 55.5% on the same backbone; Harness Primitives raise Terminal-Bench 2.0 Pass@1 from 60.0% to 72.2%. On 46 real-world tasks at heelo.dev, Claude Opus 5.5 + Claude Code completes 9 alone and 39 with HEELO via MCP; GPT-6.1 Sol + Codex goes from 9 to 35, with 1.9×–2.3× less time and lower cost. Contrast: reaching a tool is not applying it; competence must travel with the resource, not remain with the caller. Heat 4. Paper + author post + platform.

Evolver: Turning Agent Exploration into Evolving Capabilities (arXiv:2611.07595, Haoyang Zhang et al., submitted 5 Nov 2026): valuable procedural knowledge from agent exploration remains trapped in transient execution traces. Evolver extracts structured Gene assets from traces and feedback, retrieves relevant Genes at the start of a task, and revises them based on outcomes, supporting experience-conditioned execution across existing harnesses without updating foundation model parameters. Evaluated with Claude Code and Codex on Terminal-Bench 2.1, SWE-bench Multilingual, SWE-rebench, and GAIA: on a diagnostic set of 320 paired runs, task success rises from 83.13% to 87.50% while recorded token use drops 24.24%; on the 265 tasks solved under both conditions, tokens still drop 17.57%. Shipping implementation at github.com/EvoMap/evolver (recent v2 releases). Contrast: transient execution traces are not persistent, reusable procedural experience. Heat 4. Paper + discussion + repo.
