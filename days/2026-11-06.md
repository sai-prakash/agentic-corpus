# 2026-11-06

Graph-Mediated Large Language Model Systems in the Agentic Era (arXiv:2611.05953, Haihui Liu et al., submitted 4 Nov 2026): survey of graphs for structural reasoning, knowledge grounding, retrieval, memory, execution dependencies, and multi-agent communication. Introduces an operation-level role–locus taxonomy (reasoning objects / knowledge & evidence / retrieval & memory / execution programs / coordination & communication × internal inference / graph-conditioned interfaces / external traversal / agentic orchestration). Local metric gains do not always carry to downstream actions; a retrieved fact can become a tool argument that still fails. Contrast: a graph operation that improves node prediction or retrieval is not one that improves the subsequent action. Heat 4. Paper + X discussion (The Year of the Graph).

ArcRAG: Agentic Compositional Retrieval over Knowledge Graphs (arXiv:2611.06481, Jyotin Goel et al., submitted 4 Nov 2026): studies cross-construction portability of GraphRAG. Induces a query-local graph interface at inference time (node labels, relation descriptors, property keys reachable from named entities), plans multi-hop traversals, executes and repairs as Cypher. Fixed retriever config across schema-guided (typed, closed relations) and open-IE (untyped, free-text relations) graphs of MuSiQue, HotpotQA, TriviaQA. Query-time induction keeps the retriever effective when construction changes, although absolute accuracy still depends on the graph. Contrast: a retrieval procedure co-designed with one graph construction is not required for portable multi-hop retrieval. Heat 4. Paper.

HarnessGrad (Ningyu Zhang / @zxlzr, 5 Nov 2026 X post; GitHub linked): configurable workflow treating the harness as a continual learner. 8 harnesses (Codex, OpenCode, DeepSeek Harness, OpenClaw, mini-SWE-agent, MiniAgent, …), 19 improvement methods (DGM, GEPA, ADAS, ACE, SkillOpt, OPRO, Meta-Harness, …), 56 benchmark adapters (SWE-bench, Terminal-Bench 2.0, AppWorld, ALFWorld, GAIA, τ²-bench, …). Inspect candidate versions, code changes, trajectories across rounds. Core: model stays fixed; harness learns from feedback. Contrast: rebuilding experiment pipelines per harness/method/benchmark is not a shared continual-learning workflow. Heat 4. Shipping tool + discussion (extends harness-evolution cluster).

Agent Harness Awareness (arXiv:2611.05391, Manu Agrawal & Shrey Nagpal, submitted 13 Sep 2026; HTML and discussion circulating 5 Nov 2026): tool descriptions say what an action can do but not whether it is healthy now. Execution harnesses hold monitors, traces, and recent failures the model does not see—operational blindness. Trust-separated design: host supplies a small, fresh, verified state snapshot before a consequential action while retaining measurement, enforcement, and dispatch authority. On ToolRoute (216 decisions, GPT-5.6 Sol / Claude Sonnet 5 / Gemini 3.7 Flash), verified tool-health state cut mean observable policy regret 96.9% (4,252 ms → 131 ms) and raised single-dispatch completion 69.4% → 95.8%. Live end-to-end with injected faults: regret to 0 ms, 9/9 vs 5/9. Contrast: a tool description is not operational health at the moment of use. Heat 4. Paper + recent discussion.
