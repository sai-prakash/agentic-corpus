# 2026-10-29

GraphRAGProv (arXiv:2610.37237, El Amrani & Galárraga, submitted 27 Oct): executes SPARQL over source-grounded RDF graphs to return both answers and how-provenance polynomials that record which statement occurrences were used and how they combined. Each occurrence links back to exact source text, turning the query into an inspectable audit of the text-to-graph transformation. Interactive demo on 400 multi-hop cases surfaces extraction and query errors even when the final answer is correct. Contrast: GraphRAG is not just retrieval-plus-LLM; provenance makes the derivation checkable. Heat 4.

Process-Aware Knowledge Graphs (arXiv:2610.37242, Khan & Farea, submitted 27 Oct): integrates OData metadata and BPMN reference processes into a typed property graph so agents follow process order and schema constraints when invoking enterprise services. Hybrid dense + process-edge retrieval improves Recall@3 by 5.7 points on low-lexical-overlap process-chain queries (n=74). End-to-end agent completes 38.7% of 81 multi-step tasks versus 10.3% for a chunk-based baseline. Contrast: endpoints are not independent; process edges supply the missing order and payload constraints. Heat 4.

CTXAgent (arXiv:2610.34425, Busch et al., submitted 25 Oct; code: MatthiasHBusch/CTXAgent): the model itself decides when to compact, what to keep, and what hand-off to write, given two tools and one paragraph of guidance instead of a token-threshold harness. Strongest models keep live context mostly under 100k tokens with little score drop; Claude Opus 5.5 matches Claude Code task success at 34% lower cost than the explicit 200k configuration and 49% lower than default. Contrast: context management is a model policy, not only a harness threshold. Heat 4. Paper + shipping repo.

Hindsight knowledge-base MCP (Vectorize, X post 28 Oct circulating the 0.9.2 capability): knowledge pages (self-healing wiki over agent memory) are now native MCP tools on the same connection used for retain/recall. Seven operations let the agent browse, search, create, update, and prune its own pages. Heat 3 (product + discourse signal).

Low-engagement MCP commerce, coin, and generic “agentic” wraps marked heat 1 and skipped.
