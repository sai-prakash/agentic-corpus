Self-Healing Harness (2609.24130, Tayebati / Kumar / Darabi / Krishnan / Trivedi, listed this window): a self-written rule that fixes the trigger is not persistent. External Detect–Notice–Heal–Validate gate. Provisional authority during eval; cross-episode authority only after measured improvement on the trigger *and* no regression beyond a fixed margin on protected cases. 16 matched Baseline vs Harness runs on AppWorld, Terminal-Bench, τ²-Bench. Gate rejected 383 replay-decided proposals; 211 (55%) improved the trigger while degrading a case that already worked. Task-completion higher under the harness in all 16 pairs (two bootstrap intervals exclude zero); reliability higher in 12, tied in 4, lower in none. Weights stay frozen — admitted rules stay inspectable and reversible. Heat 5 under recoverable-harness / evals-gates. Pair with EvoUndo / RRSI: recoverability on a second state and OOD regularization are the same refusal applied to self-mod.

Growing Harness (2609.26760, Li / Li / Zhao / Ye / Li / Xu / Gao, listed this window): recurring control is not a context problem. Start from a strategy-free scaffold (fixed model + tool interfaces, no task controller). Function-level traces localize failures; an optimizer repairs a window jointly; a success-first held-out gate rolls back sequences that harm prior capability. Accepted edits accumulate in one shared harness. BrowseComp-Plus and WebArena-Verified, models 4B–120B: highest mean success in five of six settings, trails by 0.7 pp in the sixth. vs Tool-Calling: LLM calls −76.0–91.8%, inference cost −74.4–98.6%. WebArena-Verified stays 44.7–45.3% across scales; Tool-Calling falls to 6.7% at 4B. Ablations: trace-local edits, joint repair, and rollback each move the score. Heat 5 under agent-harness / harness-evolution. No public repo this window.
