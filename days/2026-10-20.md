# 2026-10-20

MS-Eval (arXiv:2610.22869, submitted 16 Oct by Ding et al. Westlake/Zhejiang; codes claimed at https://github.com/LINs-lab/MS-Eval): unified evaluation kit for Main-Agent Delegation and Sub-Agent Execution (MAD-SAE) in MCP-intensive working scenarios. Comprises MCP-intensive benchmark, controlled execution harness, tailored delegation/orchestration metrics, and MSQ index. Spec (sub-agent specialization) is the best practical practice; over-delegation turns cost into pure overhead. Open-source models largely competitive; gains trace to better single-agent solutions, context offloading, and genuine sub-task parallelism rather than delegation for its own sake. Contrast: Spec is not sequential tool invocation or blanket sub-agent spawning. Passes METHOD (paper + claimed shipping repo). Heat 4. Concept written.

Microsoft Scope (announced 19 Oct by Microsoft Developer Relations; MIT https://github.com/microsoft/scope, docs microsoft.github.io/scope): open-source platform for evaluating agentic coding experiences. Drives existing agents (GitHub Copilot CLI, Claude Code CLI via ACP, VS Code Copilot). Define tasks + criteria + profiles, submit requests, follow live runs, inspect structured pass/fail reports. Supports continuous DevAx learning loop. Contrast: agent experience evaluation is not a model leaderboard or single-shot pass rate. Shipping. Heat 4. Concept written.

Dynamic concurrency (arXiv:2610.10263, submitted 7 Oct by Li et al.): first systematic empirical study of native dynamic sub-agent concurrency in frontier coding agents (Codex, Claude Code, Kimi Code). Controlled enable/disable across 354 tasks / 2,124 executions. Benefits most on long-horizon tasks (LoopsBench); can degrade short bounded tasks (e.g. Claude Code SWE-bench Verified 83%→59% with concurrency). Largest failure class is shared state and merge (33%). Signal, heat 3. Mentioned on X today.

CognitiveCanvas (arXiv:2610.23559, submitted 16 Oct by Hussain et al.): interactive GraphRAG workspace that turns conversational AI memories into persistent, manipulable, audited knowledge objects. Hierarchical Semantic Fact-Graph (HSFG) distills dialogues into Goal/Fact/Code artifacts with 92.2% token reduction and multi-hop GraphRAG traversal; Continuous Temporal Drift Auditor (regex + calendar-anchored LLM) for 1-click self-correction against package/API drift; Spatial-Symbolic Prompt Compiler for 2D gestures into attention directives. Signal for context-graph and memory lifecycle. Heat 3.

flexible-graphrag (PyPI 0.8.5 / github.com/stevereiner/flexible-graphrag, update 18 Oct): shipping open-source AI context platform with document pipelines, KG auto-building, hybrid search (vector/property-graph/RDF), 13 LLMs, many DBs, FastAPI, frontends, and MCP server. Practical GraphRAG + MCP. Heat 3.
