HEXIS (2609.30123, Minghao Li, listed this window): a skill document is not control flow. Compiles skill clauses + tool interfaces into an extended finite-state machine: local instructions stay in-state; transitions and data bindings own the next operation. Incremental compiler aligns development traces, adds or reuses states, and commits only after static checks plus replay of the new trace *and* every previously accepted trace. Four benchmarks × four executors: +16.1 pp success vs Skill + ReAct. Qwen3.8-27B execution tokens −38.4–88.9%. SkillOpt + HEXIS on SpreadsheetBench: 84.2% at 69k tokens vs native optimized skill 59.6% at 257k. No public repo this window. Heat 5 under skill-memory / procedural-graph. Pair with GraphSkillEvo: graph-structured prose is still inferred control; HEXIS compiles the walk.

When Can Agents Forget Their Reasoning? / ICLR (2609.29875, Wang / Luo / Wang / Yao / Guo / Ning / Chen / Ma / Han, listed this window): executed reasoning is not still-needed reasoning. Training-free online compression ranks reasoning blocks by frozen proxy entropy; actions, tool calls, and observations stay. 260 WorkBuddyBench tasks: reward 0.699 → 0.718; input / output / cache-read tokens −25.5% / −14.4% / −33.3%. Ablations name trajectory amplification: deleting a local thought changes later interaction, so total compute is not linear in the deleted tokens. Historical reasoning is more replaceable once derived state is externalized into code, files, tool outputs, or the environment. No public repo. Heat 5 under memory-lifecycle / agent-harness. Pair with StateComp: READY-to-summarize is a write on history; ICLR is a write on the *thoughts that produced* that history.

Who Holds the Pen? / SpecHarness (2609.29921, Li / Ma / Wu / Zhong / Jiang / Dang / Hu / Ma / Guo / Huang, listed this window): a completion claim is not specification-governed state. Same model plans, acts, and declares done under specs that never leave its context. SkillsBench: 509 source-grounded task directions; seven models satisfy 79.6–86.4%; completion-claim rates exceed official evaluator pass by 28.7–37.9 pp. SpecHarness compiles visible specs into source-linked obligations; only admissible evidence from qualified providers may close them. Verifiable requirements are mediated at runtime; subjective ones stay advisory. Heat 5 under evals-gates / agent-harness. Pair with Approval Laundering and Trace tampering: a yes, a deleted log, and a self-signed done are three ways the gate never ran.

Safe Skill Retirement (2609.29543, Zhan / Ma / Haddadi, listed this window): a task-certified prune is not an authority-safe retirement. Skills bundle procedure with governing predicates (authority, consent, live state). Matched authority counterfactuals hold the requested action and intended effect fixed and flip one predicate. Two-gate certificate: keep authorized utility within a declared margin *and* produce zero unauthorized protected effects. 12 bundles × four model configs, 2,592 cells: task-certified reductions drop >94% of clauses and keep authorized completion, yet fire unauthorized protected effects in every bundle. One bounded combined protocol passes both gates on all four configs, with zero utility headroom. One read-only Home Assistant camera chain as an end-to-end check. Heat 5 under skill-memory / compositional-policy. Pair with Skilder / Scope: listing, scoping, and retiring are three cuts on the same grant.

Control the Harness, Control the Cost (2609.28919, Abbasi / Aqrawi / Kwartler, listed this window): a vendor default harness is not a cost policy.
