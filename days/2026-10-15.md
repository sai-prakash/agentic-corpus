# 2026-10-15

DKGI / Knowledge Graphs as Files (arXiv:2610.18616, Bai et al. Texas A&M / Oregon, submitted 13 Oct; shipping repo https://github.com/leopoldwhite/DKGI with code, graphs on HF, trajectories, reproduction path): an agent harness for text-rich knowledge graphs is not a fixed predefined tool API. Agents write and revise Python graph-access tools directly over complete node and edge files, interleaving with shell search and file inspection. Execution feedback guides tool revision; evolving tools guide next evidence. Training-free DKGI exceeds strongest published baseline by ≥6.7 Hit@1 on every of three domain graphs (STaRK). Paper + shipping repo. Heat 4. Contrast with constrained predefined graph interfaces even when composing tools.

STRATA (arXiv:2610.19386, Zhu et al., submitted 14 Oct): self-maintaining structured experience graphs. Three-layer graph (atomic skills/code snippets, task workflows, generalized meta-frameworks) with typed edges; five self-maintenance mechanisms sharing multi-dimensional similarity (typed reflector, community detection for meta-frameworks, pressure-triggered GC with articulation-point protection, contrast edges against direction-opposite experiences). Best average score on AppWorld/WebArena/ALFWorld/ScienceWorld, lowest latency and fewest env steps of memory-augmented methods, 44% fewer injected memory lines. Isolates single-level degradation and negative transfer (contrast edges lift ScienceWorld 78.7→96.7). Single paper so far; signal not concept. Heat 3.

Keep Your Receipts / PolyGraph (arXiv:2610.17719, Choudhary, submitted 13 Oct): trustworthy cleanup of agent-built knowledge graphs. Constructor emits receipts (alternative evidence bundles claimed sufficient) per artifact; cleanup is set arithmetic over receipts, no model calls. Re-derivation audit shows shape-matched receipts are faithful; one receipt per sentence is 100%/88% faithful and preserves most summaries. Distrusting summary layer cuts contaminated queries to 0.4%–0.8% at near-perfect recall. Single paper; signal. Heat 3.

EGCForest (arXiv:2610.19836, Cui et al., submitted 14 Oct): multi-view hierarchical memory for enterprise group chats. Immutable log into Channel/Actor/Artifact forests + Placement Map and sparse bridges. Improves accuracy up to +20.85 over MemOS on enterprise-chat benchmarks. Single paper; signal.
