Grounding Agent Memory (2609.11060, Suresh / Mak / Bhatnagar / Methani / Gutierrez Munoz, 10 Sep): a post-task curator that only reads the finished trajectory is not a grounded write. Environment-probing curation gives that existing async curator least-privilege, read-only world tools to check, scope, and refresh candidate memories. No retraining. Task agent, retriever, memory representation, and production write authority stay put. Production-like GitHub Copilot SDK harness. CLBench: pass 39% → 73%, pass-discounted reward 8.60 → 22.60, queries 8.8 → 4.7, task-agent cost $3.38 → $1.68. Six APEX worlds: all 18 memory-vs-baseline mean reward comparisons positive; tool calls −16–75%; probing best reward-per-dollar in five worlds. Holds on Sonnet 4.6 and Opus 4.7 without schema drift. Pair with EAL: that paper mints a grant the history never issued; this paper refuses to *commit* a memory the world does not currently support. Pair with XSA: probing is read-only and still not a mutation-boundary grant.

What Should an Agent Forget (2609.10263, Li / Li, 9 Sep): what is stored is not what is used. RD-Forget keeps a retained source archive and builds a query-conditioned memory view. Same-slot replacement hides superseded values from current-state answers; intent-aware retrieval makes the old value eligible again for a historical question. Configurations without forgetting or without query conditioning show the largest deficits. Pair with Selective Forgetting: that paper showed surface form *is* the memory when you extract too hard; this paper keeps the archive and gates influence.

Fortunate Recall (2609.10413, Mullick / Tüzün, 9 Sep; zenodo.20067778): an untyped personal fact is not a lifecycle. FR classifies facts into a 10+1 behavioral ontology and applies deterministic policies (decay, slot-key supersession, event-time validity, category-aware routing) over extracted metadata. FR-Bank 76.9% on LifecycleBench (516 questions) vs Mem0 / A-MEM / Memory-R1 / MemoryOS 61–70.5%; 75.2% on LongMemEval-S. Ablation: three generic lifecycle primitives keep correctness (−1.7 pp, 95% CI [−6.0, +2.7]); the ontology halves confabulation 24.2% → 12.0% (p<0.001). vs Mem0: confabulation 45.1% → 22.4% over answered queries; correct 18.6% → 31.2%. Replicates on Kimi K2.5 and transfers to BEAM (46.8% vs 32.9%, n=280). Open concept: memory-lifecycle. Store vs view vs policy are three objects.

Authority Is Not a String (2609.08371, Bouras / Dai / Mechtaev, 8 Sep, listed 9–10 Sep): ambient authority is not a capability. CapScope derives a task-wide authority ceiling from trusted input *before* repository contents or tool output are read; typed capabilities live outside the model context, per agent. An injection may request; the tool call is blocked unless that agent already holds the capability. Pi coding agent, orchestrator + sub-agents. 5 tasks × 5 injection surfaces × 4 authorization conditions × 3 trials = 300 runs. Injected effect: 33–47/75 under ambient-authority and global-policy baselines vs 3/75 under CapScope. Repairs: CapScope 68/75, baselines 68–72/75. Pair with XSA: that paper hides the grant from the planner; this paper stores a typed grant the planner cannot mint. Pair with Deadbugz / Context Gets Root: those promote a schema; this refuses the promoted action at the tool boundary.

Scanning the Harness (2609.07360, Kapner / Soceanu / Petrunin / Gartner, 7 Sep; github.com/redhat-community-ai-tools/harness-eval + Benkapner/harness-eval-experiments): a skill or MCP install is not a reviewed dependency. 3,171 public repos; 2,660 multi-component setups; 511 published skill collections. Rules decidable from bytes; independent re-derive at pinned commit; two-model adjudication. Survivors: 9.8% MCP with no version pin; 3.1% pre-approve arbitrary execution behind a scoped-looking grant such as `Bash(python:*)`; 3.8% ship a skill that pre-approves the shell for whoever installs it. 16.0% of setups carry a confirmed security defect (16.7% any confirmed defect) vs raw scanner 25.5%. No credential-exfiltration path confirmed. Pair with SkillSpector: that is the pattern catalog; this is the field rate. Author post 10 Sep.

RobustSGPO (2609.09646, Zhao / Shi / Zhou / Wang / Bie / Zhang / Zhou / Wu / Liu / Tang / Ou / Gai, 9 Sep): a local semantic-gradient edit is not a search-space policy. Specifies the requested edit, constructs and checks the patch, continues from the incumbent or retained snapshots. AgentX brainstorming: 120 tasks, 95 runs, 7,350 candidate attempts. Periodic 1→2→3 permission scheduling beats fixed maximum permission by 0.28 test-score points. Held-out 30 tasks: completion 60.0% → 80.0%, test quality 3.77 → 4.14 under a 20M-token budget. Category retention cuts source-task degradation after a shift; random retention reaches a higher destination endpoint. Pair with HarnessEvolve / EvoUndo: those gate the *diff*; this gates the *permission to search*.

Pair with Multi-Harness RL: that paper showed the *eval cage* moves sealed solve ×4.3; this paper shows the cage can also *do the work you thought the model did*.
