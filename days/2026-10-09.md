# 2026-10-09

Loud failures, quiet failures (2610.10062, Obada Kraishan, submitted 7 Oct): an explicit error is not a wrong value. The executable environments of an established function-calling benchmark are wrapped in a fault-injection layer. One of four typed faults is injected at a controlled point, and the trial records whether the agent notices, changes plan, recovers the task, or repeats itself. Six models from three families, half of them reasoning variants, ran 1,920 trials over 24 multi-step tasks. Agents treat a failure as a problem in 91.3% of trials when the tool returns an explicit error, and in 58.8% when it returns a plausible wrong value, against a 26.8% rate of reporting problems when nothing was wrong. Reasoning models, paired against instruct siblings, notice less (−9.3 points, p < .001) and change plan more (+10.4 points, p < .001); recovery is unchanged (p = .512). Two fault-free runs of the same task end in the same state only 63.3% of the time. Against that baseline, only a missing tool clearly lowers recovery (39.9%); timeouts, schema drift, and corruption stay within run-to-run variation. After a fault, agents return to the same tool three or more times in a row in up to 22.2% of trials. A prompt line asking the agent to check each result did not move detection. No code URL. Heat 4 under quiet-failure. Second source in the window: keyword harness fail-open (2610.02142). That paper scores a tool channel that stays open; this one shows the agent answers the error channel, not the content. Do not read 58.8% as a recovery rate.

SkillSandbox (2610.10088, Serin Kim / Kwangwook Seo / Dokyung Song / Jinyoung Yeo / Dongha Lee, submitted 7 Oct): a distilled skill is not a reusable skill. A Proposer names conditions to preserve and source-specific details to vary; a Builder constructs an executable scenario; a Verifier compares runs with and without the skill and issues Keep or Reject on executability, utility, and efficiency. Across ALFWorld and WebShop with three models, SkillSandbox yields the strongest downstream performance and improved execution efficiency. The abstract does not print the deltas. No code URL. Heat 4 under skill-scenario-gate. Pair with SkillForge, do not merge.

SkillForge (2610.09832, Yuyao Ge / Yiwei Wang / Yuchen He / Baolong Bi / Lingrui Mei / Jiayu Yao / Lizhe Chen / Shenghua Liu, submitted 7 Oct): a fitness lifecycle is not a scenario verdict. Skills move through trial, active, stable, and retired. A pre-RL phase retires low-fitness skills from the base model's own rollouts, seeds supervised fine-tuning, then continues selective retirement, stabilization, and LLM-guided mutation during RL. Across interactive agent benchmarks it reports the highest aggregate success rate, up to 7.8% relative improvement over the strongest baseline, and releases SkillFurnace (5k+ annotated records: filtered SFT trajectories, fitness-annotated libraries, retirement events with human-annotated failure categories). The abstract does not name the benchmarks or the baseline. No code URL. Heat 4 under skill-scenario-gate. SkillSandbox gates entry on a novel scenario; SkillForge retires during training. Two gates, one library.

HGP (2610.10071, Ran Zhou / Xueming Han / Jiaheng Liu / Yuyao Zhang / Fanyu Meng / Junlan Feng / Yuxiang Ren, submitted 7 Oct): a single vector is not a typed graph. A lightweight classifier routes into episodic, semantic, and procedural graphs (event graphs, knowledge graphs, rule trees) and extracts working memory as a state trajectory. On PAL-Set solution selection the S-score is 35.58, nearly 7 points above the strongest baseline. The abstract does not name the second benchmark or print its score. Code and data: https://github.com/Ouan6/HGP-.git. Heat 4 under hybrid-graph-memory. Second source: MINDSET (2610.08586). MINDSET versions a schema (reinforce, supersede, split, create); HGP stores three memory types as graphs plus a working-memory trajectory. Pair, do not merge. Do not read 35.58 as a general memory score.

TopoGraphRAG-Bench (2610.09360, Ruochi Li / Jianzhe Lin / Haoxuan Zhang / Haihua Chen / Junhua Ding / Edward Gehringer / Yang Zhang, submitted 7 Oct, accepted NeurIPS 2026): an entity graph is not an evidence topology. 2,024 questions over 201 long visually rich documents, built bottom-up from text, figure, and table units under three topologies (single-hop, bridge-chain, multi-source synthesis), with counterfactual checks for shortcut resistance, modality necessity, and evidence necessity. Multimodal GraphRAG is strongest overall and still fails when visual-textual alignment or multi-unit composition is incomplete. Text-only GraphRAG misses dependencies grounded in figures or tables. Page-level visual retrieval lacks the structure for topology recovery. The abstract does not print metric values. Code and data: https://richardlrc.github.io/TopoGraphRAG-Bench/. Heat 4 under evidence-topology. Second source: TAGGRAPH (2609.38353, submitted 29 Sep, revised 1 Oct). On LongMemEval-S, AdaptiveGraph reaches 0.844 MRR, BM25 0.867, OpenClaw 0.880. A layout topology can be the missing object; a history graph is not automatically the better retriever. Do not read "strongest overall" as a printed margin.

HERMES (2610.07832, Haibo Jin / Xinjie Li / Peng Kuang / Haohan Wang, submitted 6 Oct): rereading the repo is not a resident primitive. Each Dev-Primitive pairs a repository component with a resident LLM grounded in that component's implementation and dependencies, so the component can reason, talk to other components, and self-modify locally. HERMES activates primitives by dependency and maps execution evidence back to the component that must change. On four software-engineering benchmarks it beats matched baseline harnesses by 12.4% on average. With Qwen3-8B primitives plus strong activation and diagnosis models, it stays within 4.5% of the homogeneous GPT-5.6 Sol configuration, and cuts inference cost 26.2% on Terminal-Bench 4.0. The abstract does not name the four benchmarks. No code URL. Heat 4 under resident-primitive. Second source: EMHO (2610.08432). EMHO rewrites one harness from traces; HERMES moves state onto the components. Recap @ai_super_niko status 2108374483681640765 restates the abstract; it is not a second source.

HERA (2610.06563, Han Luo / Bingbing Wen / Guang Yang / Zora Zhiruo Wang / Pan Lu / Lucy Lu Wang, submitted 5 Oct; paper-bot status 2108289508240146784 on 8 Oct): a fixed task set is not an abstention environment. Controlled mutations turn solvable tasks into infeasible pairs, and failures drive both harness adaptation and new environments. On held-out tasks the evolved harness moves abstention accuracy from 61.7% to 83.3% and feasible-task completion from 68.3% to 76.7%. The best harness transfers across 19 other LLMs, +15.3 points abstention accuracy on average, with no model-specific optimization, and the abstract estimates 85% lower cost for smaller models matching stronger ones. Project: https://hera-bench.github.io/. Heat 4 under gated-coevolution. Not a new concept file. VERA (2610.05923) gates model updates and harness edits; HERA co-evolves the harness and the environment. The project page is the paper's own site.

AgentTime (2610.09944, Michael Ofengenden / Maksym Andriushchenko, submitted 7 Oct, revised 8 Oct): task completion is not runtime control. 222 tasks from 18 sources ask agents to work for a requested duration, from about a minute to multiple days, and to predict runtime and elapsed time. Fable 5.1 in Claude Code deviates by a typical factor of 2.9×; GPT-6 Astra in Codex deviates by 1.2×. Among 158 reviewed Astra runs, 14 explicitly slept after appearing to finish. Predictions overestimate natural runtimes. Removing temporal information more than doubles deviation for Sol and Astra, and nearly doubles it for Fable. Shipping repo: https://github.com/michaelofengenden/agenttimebench. Heat 4 under runtime-control. Paper plus shipping repo. Do not read 1.2× as a general Codex result.
