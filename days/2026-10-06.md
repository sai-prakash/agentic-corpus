Cogentic (2609.40324, Yang Cai / Vineet Gupta / Yanchen Jiang / Christopher Liaw / Aranyak Mehta / Grigoris Velegkas / Di Wang, Google Research, submitted 30 Sep, revised 1 Oct; recap @RealMarvelX status 2107012024681042209 on 5 Oct; @arXivBangers status 2107249573962068425; list at https://sites.google.com/view/cogentic): a population of provers is not a ledger. An orchestrator allocates independent provers across proof directions, adversarial verifiers check the drafts, and only confirmed intermediates enter a persistent verified ledger that later rounds build on. An auditor pulls lemmas out of rejected drafts and re-verifies each in isolation before reuse. The paper's Table 1 summarizes five expert-checked results in online learning, auction theory, and mechanism design; companion papers develop each result. Runs start from the problem statement. The abstract does not print call counts, token cost, or a success rate over attempted problems. No code URL on the abs page. Heat 5 under verified-ledger. Pair with Ansatz: that graph also stores the counterexample, not only the lemma that survived.

Ansatz (2610.02945, Junyi Zhang / Jinxi Yu / Eric Hanchen Jiang / Jiachen Lu / Zhi Zhang / Xinjie He / Hyunsik Chae / Ethan Ji / Alexander K. Taylor / Vigyan Sahai / Yiwen Kou / Kai-Wei Chang / Raghu Meka / Nanyun Peng / Amit Sahai / Terence Tao / Wei Wang, submitted 2 Oct; recap @arXivBangers status 2107171769966837885): a dump of attempts is not a graph. Continual Graph Memory stores facts, plans, and counterexamples with explicit edges; dependency-aware retrieval returns a local neighborhood; an evidence-sensitive curator updates the frontier; scoped recall surfaces earlier statements and negative findings for local re-proving rather than uncritical reuse. The abstract reports closure on all ten First Proof Second Batch tasks, and solutions to the Jamison caterpillar conjecture and Erdős Problems 289, 348, and 488 without human intervention, plus partial progress on several open problems it does not name. No code URL on the abs page. Heat 5 under verified-ledger. Do not read ten closures as a new base model.

Task-harness co-evolution (2610.03548, Wenlong Zhang / Zhengbo Jiao / Chenxu Zhang / Lekang Jiang / SiYuan Ma / Qituan Zhang / Guo Chen / Linfeng Zhang, submitted 2 Oct): task recursion is not harness recursion. Seeds get reused, but the construction harness stays put unless a second loop revises it. Online self-improvement turns solver failures into reusable skills during generation. Post-task self-improvement revises skills, prompts, and workflows only when the candidate makes harder valid tasks inside a bounded cost increase. Model weights and verification criteria stay fixed. Across mathematics, coding, and science, mean solver accuracy falls from 100.0% to 54.8% over fourteen evolution rounds. Both schedules together beat fixed-harness recursion or either schedule alone. A 27B student fine-tuned on 10K synthesized mathematics examples reaches 62.5% mean-16 on APEX. No code URL. Heat 4 under synthesis-harness. Pair with MOSIB (2609.37834): that loop edits the solving harness; this one edits the data-construction harness. Do not read 54.8% as a worse solver. It is a harder task set.

LiteTrajEval (2610.03315, Linh-An Phan / MingXue Wang / Guangyu Wu, Huawei Ireland; Feng Pan / Zhaoyu Pang / Yanbin Zhang, Huawei Shenzhen, submitted 2 Oct): a full trace is not a diagnosis. Offline rule profiles, then online failure marks, then a single rubric-guided judge under a fixed token budget. On public Magentic-One-style and tau-bench-style trajectory sets, failure-localization alignment with humans rises by roughly 20–35 percentage points on Magentic-One and up to 23 points on tau-retail versus AgentRx, at about 6× lower cost and more than 8× less evaluation time. The abstract does not print the absolute alignment rates. No code URL. Heat 4 under trajectory-gate. Pair with Continuous Process-Level Evaluation (2610.01833): one shows a passing final can hide a bad tool order; this shows the trajectory check itself can be budgeted. Do not read the point gains as a new agent.

HASTE (2610.02920, Xiqiao Xiong / Moxin Li / Zhixin Ma / Ouxiang Li / Wenjie Wang / Fuli Feng / Xiangnan He, submitted 2 Oct): a threat blurb is not a harness patch. A multi-agent loop evolves the harness from sparse evidence by alternating safety-specification generation and attack-case generation, then feeding evaluation back into both. The abstract says attack success falls across backbones, attack types, and evidence forms while benign utility holds. It does not print the rates. The abs page points at a code URL; https://github.com/xxiqiao/HASTE returned 404 on this run, so the repo is not a source. Heat 3 under harness-evolution. Not a concept file: one paper, no second source in the window, no printed delta.

Hold: Harness-Aware Distillation (2610.02858, Choi / Moon / Nam / Lee, submitted 2 Oct). Imitating the teacher is not distilling what the teacher adds beyond the harness. HAD contrasts the same teacher's actions with and without harness information, after the student's own reasoning, and drops pairs whose preferred action contradicts the harness record. No task reward. The abstract says it beats on-policy distillation on the same fixed harness and enters fewer unproductive loops. It does not print the deltas. No code URL. Heat 3 under harness-distillation. Not a concept file.
