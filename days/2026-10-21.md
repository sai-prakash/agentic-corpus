# 2026-10-21

Self-Evolving Agent Harness (arXiv:2610.18813, submitted 13 Oct by Wei et al.; full 66-page survey + resources at https://github.com/zgcagi/Harness-RSI, project site zgcagi.github.io/Harness-RSI/): formalizes harness RSI as feedback-driven persistent revisions to prompts, memory, workflows, tools, and control logic while keeping model weights fixed. Separates update targets from proposal/admission; distinguishes interpreted state from executable revisions. Evolutionary search analyzed via continual PAC-learning with generalization and retention bounds, high-probability admission on independent validation. Contrast: harness self-evolution is not weight update and is not unvalidated self-improvement. Paper + shipping survey/repo. Heat 4. Concept written.

Neo4j Context Engine (announced 20 Oct by Neo4j; product https://neo4j.com/product/context-engine/, coverage TechTarget, Business Wire, official X): private-preview suite that gives agents a six-layer business ontology connecting knowledge, processes, policies, data, and operational context. Includes Business Ontology, Context Build/Runtime, Context Studio governance, and Context Memory (short/long-term + reasoning memory in the same graph). Serves via MCP/APIs with GraphRAG. Contrast: context graph with governed ontology and persistent decision memory is not flat vector RAG or a static knowledge graph alone. Shipping product + independent coverage. Heat 4. Concept written.

PACT (arXiv:2610.26671, submitted 19 Oct by Zhou et al. Oxford): Plan-Augmented Coordination via Trace-graphs for dynamic multi-agent combinatorial optimization. Augments the environment graph with auxiliary plan nodes connected to resources so message-passing enables proactive (not reactive) conflict resolution as information is progressively revealed. Improves solution quality and zero-shot transfer; outperforms centralized oracles with privileged uncertainty info on large instances. Signal for multi-agent + graph. Heat 3.

STRATA (arXiv:2610.19386, submitted 14 Oct by Zhu et al.): self-maintaining structured experience graph for self-evolving agents. Three-layer typed graph (atomic skills/code, workflows, meta-frameworks) with multi-dimensional similarity, typed reflector, community detection, pressure-triggered GC, and contrast edges that flag direction-opposite experiences. Best average on AppWorld/WebArena/ALFWorld/ScienceWorld; 44% fewer injected lines; contrast edges repair negative transfer (ScienceWorld 78.7	o96.7). Signal for memory-lifecycle and graph engineering. Heat 3.

FalkorDB Agent Memory (blog updated 20 Oct, FalkorDB; draws on LongMemEval / "Does Memory Need Graphs?" ACL 2026): graph + vector memory with one graph per user fixes accuracy, latency, privacy, and cost degradation of flat shared vector memory on long-running agents. Numbers: 89% vs 76% on LongMemEval; ~4.5x fewer tokens; no cross-user leakage. Practical shipping pattern. Heat 3.
