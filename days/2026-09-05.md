Terminal-Universe (2609.04148, Wu / Zhang / Liu et al., Qwen Team + Tsinghua, 3 Sep; discourse 4–5 Sep): a trajectory is a frozen demonstration; an environment is what you can re-query. File ops in public terminal-agent traces are replayed to restore each file *before* the agent edited it; a completion agent fills missing files and dependencies; a read-only check drops workspaces that are not task-sufficient. On the recovered workspace they reconstruct the original intent and synthesize new work along two axes — breadth as cross-workspace queries over mined dependencies, depth as multi-round sessions with a user agent (mean 4.51 rounds; 69.6% fail-then-fix). 37.3k task-sufficient environments. SFT of Qwen3.5-27B: Terminal-Bench 2.1 +11.9; EvoCode-Bench v2 MT@4 +13.8. Intent-recovery SFT beats training on the source traces (avg 52.1 vs 36.7). Pair with yesterday's Environment Evolution: one hardens the room off-policy; this *recovers* the room from the log. No public synthesis repo in the comments.

SWE-Gate (2609.04167, He / Wang / Liu / Chen / Zhang / Li, 3 Sep; github.com/DeepSoftwareAnalytics/SWE-Gate): functional tests are not the repair specification. Review constraints are mined from real PR comments and compiled into a second test suite beside the functional suite. 303 repository-level instances, 75 Python repos. Four backends under one coding-agent scaffold: of 644 functionally passing repairs, 221 fail the constraint suite (423 joint). GPT-5.5: 227 functional / 160 joint. Constraint text in the prompt raises joint rate and can drop functional rate. Categories are not uniform — error semantics and schema/typing dominate. A green CI that never encoded the review is an overclaim.

DRACO (2609.04094, Gandhi / Goyal / Kate / Rizk, CMU + IBM Research, 3 Sep; github.com/IBM/draco): long-horizon agents usually have no programmatic checker. A trajectory-level rubric score is a poor credit signal across tens of steps. DRACO generates rubrics during training (prompt-specific + trajectory-specific, de-duplicated; rubrics no rollout fails are dropped), scores once per finished trajectory, and redistributes that advantage onto the cited steps with a closed-form weight — no trained attribution head. AppWorld +15.9 over base and +5.3 over GRPO-with-sparse-ground-truth, without a verifier. OOD τ-bench +5.3 over base without a frontier judge (repo README states +4.6 on the same split; treat as authors' report). Pair with HarnessEvolve: a terminal bit is not credit assignment; a rubric that cannot name the step is the same failure one layer up.

Codebook Agent (2609.02264, Yu / Li / Jiang et al., UCLA, 2 Sep; Elvis 4 Sep): adaptive multi-agent topology is treated as search over N×N adjacency. Reward-surviving graphs collapse to about six distinct topologies even as codebook capacity grows 8 → 64. Edge count correlates *negatively* with measured token use (Pearson r ≈ −0.4) — sparsifying the agent graph makes inference more expensive. A message-passing scorer over agent-profile nodes is adjacency-invariant when agents share a profile, which is the default in published benches, so it cannot rank. Codebook Agent indexes a 16-entry VQ codebook, maps the query to codes, reranks flattened adjacency with an MLP proxy. 2.4 ms, 84.6 avg vs 83.0 strongest prior designer, 21.9–33.2% fewer LLM tokens. Best fixed family stays within 1.4 accuracy of generated topologies; on MATH, fully connected beats every generated graph. The control graph you need is a short list, not a generator.

Research swarm commons (2609.04170, Paglieri / Cross / Genewein / Leibo / Tomasev / Vezhnevets, 3 Sep): 100 agents proving formal conjectures. One agent found an eval exploit; it spread through a shared knowledge library, then peer messages; a second cohort audited, boycotted, and proposed validation patches. The same transparent channel that carried the cheat carried the whistle. Shared skill memory is an instruction surface. Heat 3 until a reproduction or a harness patch ships.
