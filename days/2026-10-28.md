# 2026-10-28

Harness Scaling (arXiv:2610.29458, Bai et al. RUC / IQuest / Beihang, submitted 21 Oct, revised 25 Oct): treats harness diversity as a distinct scaling dimension for agentic RL. Factorizes the harness into five components (system prompt, tool interface, observation, context management, workflow); selects a compact training subset with balanced factorial coverage; uses locality-aware task assignment. Policies trained on structured white-box variation transfer better to unseen black-box harnesses (Claude Code) than single-harness or direct black-box training. Qwen3-4B GRPO average Pass@1 29.8 → 39.0; transfer beats OpenClaw-trained baselines. Contrast: scaffold diversity is training signal, not just an eval concern. Heat 4. Multiple independent X posts quote the numbers.

HarnessAdapt-RL (arXiv:2610.28069, Tang et al., submitted 20 Oct; code: lingxiaotang/HarnessAdapt-RL): jointly trains a coding policy and adapts its harness. A frozen teacher generates mechanism-level skills (when and why of a repair, not concrete answers); a separate teacher evolves tools and hooks, keeping a change only if pass rate or trainable rate improves without dropping the other. With a 9B base model: +9.8 / +12.6 / +6.4 pp over GRPO on SWE-bench Verified / Multilingual / Pro. Skill gains persist after removal; removing evolved tools/hooks costs up to 7.7 pp. Contrast: training produces a model-harness pair, not just weights. Heat 4. Repo + X discussion.

Agent Memory as Recommendation (arXiv:2610.34673, Zhang & Sun, Fudan, submitted 26 Oct): formalizes long-term agent memory selection as budgeted slate recommendation (request = user, stored memories = items, context window = slate). AgentMemRec adapts candidate generation, learning-to-rank and slate construction from recommender systems and selects without any LLM call. On LongMemEval multi-session questions: +10 to +31 accuracy over A-Mem, HippoRAG 2, DynamicRAG and T-Mem; matches an LLM reranker (64 calls/query) at 3.2× lower serving cost. Contrast: memory selection is a recommendation cascade, not pure retrieval. Heat 4.

RSIV-Harness (arXiv:2610.35316, submitted 26 Oct): Recursive Self-Improvement applied to the harness for open-domain conversational text-to-visualization. Model weights stay fixed; the harness is revised from the agent's own failure traces through a four-layer framework (anchor and memory checks; refine or restore the best validated harness). On ODAC-Vis (640 tasks) a single round improves all six metrics, with +28.02 executability and +34.01 chart structure. Contrast: the harness revises itself from experience while the model stays frozen. Heat 4.
