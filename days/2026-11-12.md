# 2026-11-12

**TreeAgent**: Structure-Aware Memory Agent for Processing Long Hierarchical Data (arXiv:2611.13946, Wei Gu, Weiwei Qi et al. from Zhejiang University and Alibaba, submitted 10 Nov 2026): memory agents that process long inputs segment-by-segment lose hierarchical context and can discard sibling details needed later. TreeAgent constructs segments from complete subtrees and groups of adjacent siblings, attaches structural paths, and uses residual links to retrieve relevant spans from historic memory states. Theoretical bounds guide token budgets to match fixed-length segmentation. On eight retrieval and aggregation tasks over JSON/HTML/YAML/JS inputs from 8K to 1M tokens, it improves the average score of four representative memory agents by 3.61%. Contrast: flat sequential segments are not structure-preserving; residual hierarchical memory access is. Heat 4. Paper + public repo.

**WorkflowArena**: Benchmarking Executable Workflow Orchestration in LLM-Based Multi-Agent Systems (arXiv:2611.12856, Einsia AI / Navers Lab, submitted 9 Nov 2026): agent harnesses now let models spawn workers and author the coordinating workflow, yet existing benchmarks measure only end-to-end success or evaluate under fixed structures. WorkflowArena formalizes orchestration quality with 145 long-horizon tasks across 8 domains (SWE, formal math, law, 3D, etc.) and a hidden verifier; all delegation is recorded. Best overall resolved rate is 36.95% (Claude Opus 5.5 in Claude Code at max effort); no configuration leads every domain. Distinct strategies appear: Claude models launch fewer but larger worker groups. Contrast: task completion is not the same as autonomous workflow organization quality. Heat 4. Paper + repo + project site + independent discussion on X.
