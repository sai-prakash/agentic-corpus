# 2026-10-22

Agentgateway (shipping repo https://github.com/agentgateway/agentgateway, ~5.5k stars, Linux Foundation / Agentic AI Foundation project; docs https://agentgateway.dev; independent coverage Archestack 21 Oct): open-source proxy that unifies LLM routing (OpenAI-compatible, budgets, failover), MCP tool federation (stdio/HTTP/SSE/Streamable HTTP, OpenAPI, OAuth), and A2A agent-to-agent traffic under one data plane with JWT/API-key/OAuth auth, CEL RBAC, rate limits, guardrails, and OpenTelemetry. Standalone YAML or Kubernetes Gateway API controller. Contrast: a governed agent gateway is not a pile of ad-hoc MCP servers or separate LLM proxies. Shipping product + coverage. Heat 4. Concept written.

OO-Harness (arXiv:2610.28380, submitted 20 Oct by Li et al.): evolves a hierarchy of executable harness classes via object-oriented inheritance; evolution agent creates specialized subclasses from execution records; test-time router selects using accumulated routing lessons. Best on three long-horizon benches (business workflows, workspace, tool use) with up to ~15% absolute gain over base. Signal for specialized harness evolution. Heat 3.

RiseHarness (arXiv:2610.27435, submitted 20 Oct by Wang et al.): reliability-oriented harness self-evolution for long-horizon terminal agents. Focuses on tasks that flip between success and failure under the same config; contrasts successful runs with failures; combines trajectories + internal harness traces + Harness Handbook to locate shared mechanism defects; borrows designs from other frameworks; retains only measured gains. Improves Pass@1 and consistent-success fraction; treats a specific model as the adaptation unit. Signal for reliability gates in harness evolution. Heat 3.

HarnessPro (arXiv:2610.26770, submitted 19 Oct, revised 20 Oct): label-free recursive harness self-improvement with Pareto selection for performance-cost trade-offs. Emits lite/medium/heavy harnesses; heavy mode averages +2.0 pp pass rate and -26.1% cost vs prior RSI baseline on Terminal-Bench 2 / SWE-Bench Pro / ProgramBench. Signal for multi-objective harness evolution. Heat 3.
