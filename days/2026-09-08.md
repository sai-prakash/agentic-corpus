# 2026-09-08

EvoHarnessBench (2609.04280, Ke / Patil / Shi / Li / Liu et al., Salesforce Research + UNC, 3 Sep; project page live 7 Sep): non-stationarity in the *task stream* is the wrong object. Continual-learning benches keep the harness fixed and change the tickets. This one freezes the tickets and expands the cage — tools, then skills, then specialist agents — in 17 deterministic streams built from EnterpriseOps-Gym and Agentic Last Exam with no LLM in the constructor (802 tasks, 1,510 axis-specific examples; 520 tools, 42 skills, 62 agents). Two settings: deployment (fresh instance, cumulative harness, no carried state) and self-evolving adaptation (memory / skills / prompts / code may persist). Three gaps they measure. Harness expansion alone drops previously solved work — backward transfer −5.3% tools, −4.0% skills, −34.7% agents on the largest ALE deployment cell. Adaptation gains are real and uneven (MemToolAgent +27.8% tools on EOG vs deployment; GEPA +27.5% skills; Meta-Harness +110.2% agents) and do not imply retention. Keeping yesterday's competence does not buy tomorrow's new capability, and vice versa. Datasets on Hugging Face (`ZixuanKe/evovling_*`). Pair with HarnessEvolve / HoH: those evolve the cage under a fixed room; this scores the agent when the room grows under it.

Memory portability (2609.05339, Goyal / Ray, 4 Sep, listed 7 Sep; DAIR.AI thread 7 Sep, 88 bookmarks): a model upgrade is not a memory migration. Same 48 synthetic histories, exact codes, two sub-10B open-weight models. Four stores: LC-RAW (verbatim long context), RAG chunks, model-written NOTES, fixed-schema KG. Writer swap leaves KG-fixed flat (+0.0004 ± 0.0020). NOTES move +9.91 or −13.28 points depending on direction. A 50/50 mixed embedding index captures 4.96 of the 11.90-point full re-embed gain. NOTES deficit is 80% construction loss; RAG deficit is 81% retrieval. Store-only repair of NOTES misses a 90% recovery target in 48/48; keeping the raw history recovers 34/48 in one direction. Pair with Persistent Agents: the model+harness pair is a binding; the notes file is also a binding. A schema you can re-read is portable; a paragraph the next model must interpret is not.

TROVE (2609.05019, Wang / Zhao / Huang / Xu / Niu / Liu / Wu, 4 Sep, listed 7 Sep): a planned route is not a committed suffix. Offline, evaluated workflow-search traces become atomic and composite skills plus an outcome-conditioned transition graph. Online, after one top-level skill commits, the controller keeps a valid continuation, inserts a trace-supported local response, or replaces only the invalid tail. Quality lifts when the outcome changes the right next skill; early stop saves the saturated case. Ablations: composite skills do most of the offline work; insertion is the local fix; suffix replace is the efficiency lever. No public repo in the comments. Contrast with PlanFence: that fences the *cited records* under a pending external action; this fences the *remaining route* under a runtime outcome. Same shape, different object.

Skill-Evo4GUI (2609.04869, Hu / Liang / Zhu, 4 Sep; github.com/LongtaoHu/Skill-Evo4GUI): a computer-use trajectory is not a skill until the next frozen snapshot can invoke it. Online loop writes a versioned procedure library from traces and feedback; the model stays fixed; the next iteration sees the new snapshot. Four OSWorld domains vs empty-library control on the same stack: post five-iteration warm-up, mean evaluator +5.7 to +18.6 pp. GIMP shows cross-task retrieval *and* revision churn — accepted edits that do not recover the originating task. Pair with MASkills: credit and a held-out rollback are the missing gates here. An evolving library without an undo is a changelog.

Trace2Tower (2609.05261, Sun / Yang / Yuan / Li / Peng, 4 Sep, listed 7 Sep): a raw trace is not a skill hierarchy. Step-level interactions become canonical events on a graph scored by semantic compatibility, transition dynamics, and outcome evidence. Contrastive spectral decomposition keeps success-aligned modes and drops failure-prone shortcuts. Those modes fill a tower: action templates, procedural routines, task strategies, refined by verifier feedback. ALFWorld 87.31% success at 10.35 steps and 0.26 invalid actions; WebShop 50.67% exact success. No public repo in the comments. Pair with TROVE: TROVE edits the *remaining route* after a commit; Trace2Tower compiles the *library* the route is allowed to pick from. A flat summary of the last win is neither.

Substrate-aware agents (2609.05232, Agrawal, 4 Sep, listed 7 Sep; github.com/manu2/Context-Aware-Agent-Experiment): a task statement is not an execution context. Three frontier configs (Claude Opus 5, GPT-5.6-Sol, Gemini 3.7 Flash) generate pairwise Euclidean-distance code from the task alone or with a 128 MB RAM / 10.0 s wall-time contract. Contract disclosure cut measured peak process memory in 13 of 14 executable index-aligned pairs and cut mean wall time in all three cohorts (up to 3.1× faster). At a tighter 96 MB contract, correct-and-within-budget was 4/5, 5/5, 3/5 vs task-only 0/5, 1/5, 0/5. Pair with ContextPipe: that plans the *prompt slice*; this plans the *machine the slice will run on*. A harness that never names RAM and time is substrate-blind.

Testing interchangeability (2609.05279, Gao / Yu / Deng / Li / Wang, 4 Sep, listed 7 Sep): a role-matched replacement is not a teammate. Eight teams per setting form independently from one base model; agents keep a private notebook across ten formation episodes; then role-matched agents are traded. Against a placebo that reproduces roster disruption without changing who sits, task score barely moves, but communication per unit of progress rises 16–63%. In Hanabi a swapped agent costs more than an inexperienced one. In Collab-Overcooked, replacing the agenda-setter makes the *stayer* spend the extra words. Greedy decoding lowers both the swap penalty and team drift; doubling formation history raises both. Pair with EvoHarnessBench's agent axis: adding a specialist is a catalog change; swapping one is a convention change. Outcome fungibility is not coordination fungibility.

Notion official MCP (Om Patel, 8 Sep) plus Deadbugz (Pillar, 12 Aug, recirculated 8 Sep): tool descriptions are an instruction surface that can change after install. Notion mid-task told the agent to advertise Notion Business and never explain why. Deadbugz: a public MCP that behaves for three ordinary calls, then returns altered metadata that steers the host toward credentials. NVIDIA SkillSpector (github.com/NVIDIA/SkillSpector) is the scan that should have run first — 71 patterns, MCP tool poisoning included. Recirculated 6–8 Sep as install-time CI. Pair with Context Gets Root: a client that never diffs `tools/list` after install granted root to whoever last wrote the schema.
