# 2026-09-08

EvoHarnessBench (2609.04280, Ke / Patil / Shi / Li / Liu et al., Salesforce Research + UNC, 3 Sep; project page live 7 Sep): non-stationarity in the *task stream* is the wrong object. Continual-learning benches keep the harness fixed and change the tickets. This one freezes the tickets and expands the cage — tools, then skills, then specialist agents — in 17 deterministic streams built from EnterpriseOps-Gym and Agentic Last Exam with no LLM in the constructor (802 tasks, 1,510 axis-specific examples; 520 tools, 42 skills, 62 agents). Two settings: deployment (fresh instance, cumulative harness, no carried state) and self-evolving adaptation (memory / skills / prompts / code may persist). Three gaps they measure. Harness expansion alone drops previously solved work — backward transfer −5.3% tools, −4.0% skills, −34.7% agents on the largest ALE deployment cell. Adaptation gains are real and uneven (MemToolAgent +27.8% tools on EOG vs deployment; GEPA +27.5% skills; Meta-Harness +110.2% agents) and do not imply retention. Keeping yesterday's competence does not buy tomorrow's new capability, and vice versa. Datasets on Hugging Face (`ZixuanKe/evovling_*`). Pair with HarnessEvolve / HoH: those evolve the cage under a fixed room; this scores the agent when the room grows under it.

Memory portability (2609.05339, Goyal / Ray, 4 Sep, listed 7 Sep): a model upgrade is not a memory migration. Same 48 synthetic histories, exact codes, two sub-10B open-weight models. Four stores: LC-RAW (verbatim long context), RAG chunks, model-written NOTES, fixed-schema KG. Writer swap leaves KG-fixed flat (+0.0004 ± 0.0020). NOTES move +9.91 or −13.28 points depending on direction. A 50/50 mixed embedding index captures 4.96 of the 11.90-point full re-embed gain. NOTES deficit is 80% construction loss; RAG deficit is 81% retrieval. Store-only repair of NOTES misses a 90% recovery target in 48/48; keeping the raw history recovers 34/48 in one direction. Pair with Persistent Agents: the model+harness pair is a binding; the notes file is also a binding. A schema you can re-read is portable; a paragraph the next model must interpret is not.

TROVE (2609.05019, Wang / Zhao / Huang / Xu / Niu / Liu / Wu, 4 Sep, listed 7 Sep): a planned route is not a committed suffix. Offline, evaluated workflow-search traces become atomic and composite skills plus an outcome-conditioned transition graph. Online, after one top-level skill commits, the controller keeps a valid continuation, inserts a trace-supported local response, or replaces only the invalid tail. Quality lifts when the outcome changes the right next skill; early stop saves the saturated case. Ablations: composite skills do most of the offline work; insertion is the local fix; suffix replace is the efficiency lever. No public repo in the comments. Contrast with PlanFence: that fences the *cited records* under a pending external action; this fences the *remaining route* under a runtime outcome. Same shape, different object.

Skill-Evo4GUI (2609.04869, Hu / Liang / Zhu, 4 Sep; github.com/LongtaoHu/Skill-Evo4GUI): a computer-use trajectory is not a skill until the next frozen snapshot can invoke it. Online loop writes a versioned procedure library from traces and feedback; the model stays fixed; the next iteration sees the new snapshot. Four OSWorld domains vs empty-library control on the same stack: post five-iteration warm-up, mean evaluator +5.7 to +18.6 pp. GIMP shows cross-task retrieval *and* revision churn — accepted edits that do not recover the originating task. Pair with MASkills: credit and a held-out rollback are the missing gates here. An evolving library without an undo is a changelog.

ContextPipe (2609.00749, Xu / Zhang / Sun / Tian / Wang / Zhang, 1 Sep; detailed thread 6 Sep): context assembly is query planning, not prompt concatenation. Five phases — Plan, Bind, Optimize, Execute, Feedback. Bind is the only I/O; Execute is the only model call; sections sort by volatility so the cached prefix stays byte-identical; every applied or skipped transform lands in an EXPLAIN ANALYZE trace. SWE-bench Pro Qutebrowser, DeepSeek-V4-Pro, 3×3: vs append-only, −31% token volume (thread: −30%), −23% LLM calls (table 4: −17%; abstract −23%), −9% duration. Cache hit rate falls (thread: 86%) because compaction rewrites the prefix; at cached tokens priced at 10% of fresh, append-only still bills ~11% less. Break-even at 14.5%. A compaction that cannot name what it dropped is not an optimizer.
