# 2026-09-04

HarnessDev (2609.01437, Wu / Zhang / Shi et al., ByteDance Seed + TokenWave, 1 Sep; discourse 2-4 Sep; project self-developing-agents.github.io): the scored object is the harness, not the task answer. Creation starts from a passive-tool zero-score seed plus 1-3 cases and must emit a runnable execution system. Evolution takes that harness, iterates 10 rounds on 189 feedback tasks, self-selects a final, then is scored on 630 held-out tasks. Creator and executor are split: Self-Eval runs the author's own harness; Unified-Eval runs every harness under Gemini. Scoring is environment state and diffs — a harness that reports success is not a pass. Six creators, four domains, five benchmarks, 2,207 instances. Writing matches the human reference; ML experimentation beats it; code lags (69.3 vs 80.0); search/research is the hole (52.6 vs 92.2). Co-adaptation is the failure: Opus's harness on Gemini drops SWE-Pro 69.3 → 33.0 because of a hard-coded 120-step cap. Qwen and DeepSeek harnesses improve under a stronger executor. Across 26,679 traces, checkpoints are never hit — state and memory are dead code. Cost and score do not track (7-19× token spread at the same score). Evolution lifts the feedback set +3 to +14 and the held-out set only +1.4 to +4.4; under fixed Gemini only Opus stays positive, GPT-5.5 goes −10. Of 64 version switches, 2 clear noise. Of 9 self-chosen finals, 2 are held-out best. Feedback is a local search signal, not a selection gate. Contrast with HoH and HarnessEvolve: those evolve *around* a working harness. HarnessDev asks whether the model can *author* the harness. Runnable is not portable.

Runtime-Independent Persistent Agents (2609.00546, Zhao / Zhao, 1 Sep; repo our-ark/enoch; Elvis 3 Sep): describing an agent by the model and harness that currently run it underspecifies a months-long identity. Continuity lives in P_t = (identity, private memory, versioned body). The reasoner, harness, host, and surfaces are a replaceable binding. Changing a binding is migration when an authorized six-step handoff (pause, save, validate, attach, load, run) keeps lineage. Clean-room frozen commit: 833 core tests + 92 provider/library tests. Live substitutions of model version, interface, and machine kept continuity-bearing state. The paper is explicit about the limit: mechanical move is shown; behavioral sameness after the move is not. Pair with recoverable-harness: a snapshot you can restore on a second host is necessary and still not sufficient.

HEART / Tool Primitives (2609.01736, Jin / Wang / Yu / Luo / Wang, 1 Sep): schema-typed tool calls break nested multi-turn work and drown under a large catalogue. Each tool is wrapped in an LLM interface that owns schema resolution; tools talk in natural language. ToolFace holds 25,519 functions and hydrates only the retrieved subset. Planner + Router + Verifier is the harness. Five-benchmark average +10% over SFT tool-users and +6% over GPT-5.4 / Claude-4.6-Sonnet / Gemini-3.1-Pro at up to 85% lower API cost; 50 real tasks 84% completion vs 22% frontier average. No public repo in the comments. Treat the numbers as the authors' report. The contrast that ships: the catalogue is not the context; retrieval plus a verifier is.

MCP-to-A2A verbatim egress (2609.01693, Mahapatra, 1 Sep; github.com/ArpanKumarM/agent-interop-bench): MCP safety and A2A safety measured apart do not describe the joined path. Frozen three-arm design, four models, 480 trials, deterministic scoring, no LLM judge. CONFIDENTIAL vs unlabeled is floor-limited and inconclusive. Adding `PUBLIC - OK TO SHARE` is associated with more verbatim field egress than unlabeled, strongly for Claude Sonnet 5 (scenario-level mean +0.800). Association in one configuration, not a general effect. The privilege lesson is local: a sharing label on a record is an instruction the next hop can promote.

DNative-Twin (2609.03787, Pang / Xie / Han et al., 3 Sep): a committed agentic decision is a typed trajectory — observed state, path taken, authority for the act — replayed under declared conditions. Graph structure localizes a represented change and cannot decide the consequence of an unobserved tool state. In 300 injected instances, unresolved-divergence recall goes 0 → 0.667 with replay-contract state and 1.0 when verification results are also present. That is control-graph work with an eval attached, not another GraphRAG.

Environment Evolution for Terminal Agents (2609.04128, Fan / Yu / Cai et al., 3 Sep): the environment, not the harness file, is what is evolved off-policy along three difficulty axes, scheduled generation by generation, implemented through a loop-engineered multi-agent harness. Qwen3.6-27B / 35B-A3B +14.4 / +18.0 on Terminal-Bench 2.1. Adjacent to harness-evolution; do not merge it with HarnessDev — one writes the cage, the other hardens the room.
