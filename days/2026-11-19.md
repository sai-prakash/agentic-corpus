# 2026-11-19

**Self-Improving Harness Framework (Gated modular evolution beats full rewrites)**: arXiv:2611.22299 (Deep Shah, Nehal Kathrotia, submitted 17 Nov 2026). Pairs four editable runtime components (context/state, agent control, action interfaces, verification/recovery) with a four-stage diagnose-propose-validate-deploy loop. Full-harness rewrites overfit or break across modules; modular updates with validation gates generalize across models on SWE-bench Lite at a fraction of the token cost, discovering mechanisms such as pre-stop verifiers and loop breakers. Contrast: a static harness tuned for one model is not a self-inspecting runtime that rewrites its own code under gates. Heat 4. Paper + prior Self-Harness (arXiv:2606.09498).

**Surfacing Disagreement Memory (Preserve contradictions, do not collapse them)**: arXiv:2611.22461 (Ziaullah Khan et al., submitted 17 Nov 2026). In DebateGraph, preserving contradictions and passing the ranked conflict set to multi-agent debate improves F1 by +0.340 (95% CI [+0.267, +0.414]) and cuts attack success from 22 to 7 of 122 poisoned items, at equal cost. Other mechanisms (write trust-gate, provenance features) cost accuracy once contradictions reach the prompt. Contrast: shared memory that silently resolves to one winning fact is not memory that surfaces the ranked conflict set for the debate to see. Heat 4. Paper + released harness/attack set/logs.

**BRIDGE Minimal Memory (Block notes reach recall parity; action probes split designs)**: arXiv:2611.22179 (Jingyu Liu et al. / UChicago & UC Berkeley, submitted 17 Nov 2026; NeurIPS 2026). Deliberately minimal RAG (chained observation notes, hybrid BM25+cosine, chronological render) matches prior SOTA within CI on LongMemEval-S and BEAM, beats best memory baseline on EverMemBench by 5.7-6.3 points, at ~5-7K tokens and one LLM call per ingest/query. On five adversarial probes that require applying a remembered rule/pattern the query never mentions, atomic-fact extractors (LangMem) win rule application while BRIDGE wins pattern induction. Contrast: stacking extraction, reflection, and graph synthesis is not automatically better than block-summary notes; what matters is what the agent can do with the retrieved memory. Heat 5. Paper + official repo + X discussion.

**Skills over MCP (One shared skill catalog, not per-laptop folders)**: VS Code 1.147+ (blog 18 Nov 2026) + FastMCP 4.2 SkillCatalogProvider. MCP servers can now serve SKILL.md + supporting files as resources (and via the Skills extension); clients such as VS Code + Copilot load them so every agent reads the same copy and receives updates on deploy. Contrast: a local skills folder that drifts per machine is not a remote catalog served next to the tools it describes. Heat 4. Shipping client + framework + SEP-2640 extension.
