# Harness evolution

**Definition.** Improve the wrapper, not the weights. Outer loop proposes harness changes; evals keep or reject.

**Contrast.** StarHarness / Recuris still assume a human or search loop over harness code. JIT-Agent trains a generator that emits the harness at task time. Harness-G changes the *interface* (finite graph actions, not free-form queries). HarnessLens changes the *verifier*: do not score every candidate on a fixed task set. Predictable harness (2608.26197): a first-pass FSM wrapper is mixed; the leftover variance is unconstrained free-text planning. Schema-validate the plan before any tool and three of four cells hit reproducibility 1.000 at N=100. Self-orchestration (2608.26480) is a one-shot scaffold change, not an evolution loop — gains are real and model-conditional. openJiuwen (2608.27969): the missing pair is Structural Composability plus Runtime Adaptivity — Rails under one substrate, evidence moves framework decisions, model policy stays fixed. EvoUndo (2608.28363): a mutation that raises the score is not admissible until recoverability holds on counterfactual states. Warp: the searchable object can be a skill file. Inner skill executes; outer skill reads human corrections and opens a diff. That is evolution with a merge gate, not mid-task CRUD on the prompt. Harness-of-Harness (2609.01481): the outer object is a plan–code–test loop over an *existing* coding harness. Implementation-time tests stay inside the loop; independent evaluation scores the iteration. Average relative +52.25% after three iterations on three harness–model pairs; 70+ unattended loops produced a playable game. HarnessEvolve (2609.00829): credit assignment needs a reference trajectory (the run given the gold answer), not a terminal bit. Quality gate kills leakage and prompt bloat; performance gate refuses an edit that lifts this batch and drops recent ones. HarnessDev (2609.01437): the model is asked to *create* the harness from a weak seed, then evolve it for 10 rounds. Feedback-set gains (+3 to +14) shrink on held-out (+1.4 to +4.4); under a fixed executor only Opus stays positive. Self-chosen finals are held-out best 2/9 times. Read-failure-then-patch correlates 0.57 with score; stacked self-tests do not. Environment Evolution (2609.04128) evolves the *room* off-policy, not the cage file — keep the objects apart. All of these are harness work, not model work.
