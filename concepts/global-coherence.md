# Global coherence

**Definition.** A team is coherent only if local views glue into one world the harness can commit. Local validity is a property of an observation. Coherence is a property of shared state.

**Contrast.** A locally valid act is not a coherent team. Global Coherence (2610.02036) states the boundary: if k indistinguishable worlds require pairwise-disjoint actions, best randomized worst-case success is 1/k, and more reasoning, roles, messages, or samples do not recover the missing distinction. Models propose; the harness owns shared state and governs commit. Same frontier model: 40/40 when the deciding event is visible, 12–17/40 when hidden, 40/40 when one authoritative fact is restored. TeamBench budget violations 5/5 without enforcement, 4/5 with a visible live count, 0/5 with commit enforcement. tau2-bench Telecom: current-state checks 0.07 after silent reverts, harness 1.00. MAS mechanism diagnosis (2609.38761) is the record side of the same split: a correct answer is not an intact collective mechanism, and removing records can make a conclusion unknown but cannot reverse one. A right local act and a right final answer are different failures.
