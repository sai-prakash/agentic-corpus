# Neo4j Context Engine

**Definition.** Enterprise suite that materializes a six-layer business ontology as a governed context graph so agents can reason over knowledge, processes, policies, data, and operational history, with persistent short/long-term and reasoning memory in the same graph, served via MCP and GraphRAG.

**Contrast.** Context graph with ontology + decision memory is not flat vector RAG and is not a static knowledge graph of domain facts alone. Every answer and step is meant to be governed and explainable; memory lives alongside business meaning.

**Heat.** 4. Updated 2026-10-21.

Sources: Neo4j announcement 20 Oct 2026 (https://neo4j.com/product/context-engine/, Business Wire, TechTarget); official X.
