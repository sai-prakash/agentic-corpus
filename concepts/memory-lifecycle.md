# Memory lifecycle

**Definition.** Policy over a durable archive that decides which stored facts may influence the current answer, which must be refreshed against the world, and which stay eligible only for historical queries. Not the graph schema and not the prompt.

**Contrast.** A write into memory is not a grounded working set. Grounding Agent Memory (2609.11060): a post-task curator restricted to finished trajectories can preserve errors, overgeneralize, or keep stale knowledge. Giving that curator least-privilege, read-only world tools — environment-probing curation — leaves the task agent, retriever, representation, and production write authority unchanged. GHCP SDK harness, CLBench pass 39% → 73%, reward 8.60 → 22.60, queries 8.8 → 4.7, cost $3.38 → $1.68; 18/18 APEX memory-vs-baseline mean rewards positive. RD-Forget (2609.10263): what is stored is not what is used. Keep the source archive; build a query-conditioned view. Same-slot replacement hides superseded values from current-state answers; intent-aware retrieval puts them back for a historical question. Dropping forgetting or dropping query conditioning produces the largest deficits. Fortunate Recall (2609.10413 + zenodo.20067778): an untyped personal fact is not a lifecycle. A 10+1 behavioral ontology plus deterministic decay / slot-key supersession / event-time validity / category routing. FR-Bank 76.9% on LifecycleBench vs 61–70.5% for Mem0 / A-MEM / Memory-R1 / MemoryOS. Generic lifecycle primitives carry correctness (−1.7 pp, 95% CI [−6.0, +2.7] vs the typed layer); the ontology halves confabulation 24.2% → 12.0%. Pair with EAL: a row that mints a grant is a failed lifecycle write. Pair with Selective Forgetting: deleting surface form is not the same as controlling influence. Pair with memory-graphs: the graph is the address space; the lifecycle is which addresses the current view may touch. ChurnBench (2609.11515 + vsingh45/churnbench): a retrieved fact that was true at fetch can be false at answer time. Gold lives on an append-only ledger. With scheduled refresh, cache age does not predict freshness errors (7 / 4 / 4 at 1 / 14 / 28 days); kill the TTL and 28-day freshness errors go 4 → 45. The lifecycle object is refresh policy against entity churn, not "how old is this embedding." AgentRecall (Goldentrii/AgentRecall-X): a corrections ledger is a lifecycle view over misses. Capture recall 35.3%; heed 0/3 after reset; transfer 0/4 in the instrument they reset. Publishing the zero is the point — a SKILL.md that is never replayed did not enter the working set. Pair with Osmani: write the miss into the skill, then measure heed on a reset session, not on the same context window. AIM (2609.12320): a single-user store is not a multi-user memory — classify private vs public and enforce index-level ACLs; MUMBench 96.0% visibility / 58.8% strict ops / 70.5% state-aware. LifeFuse-Mem (2609.12436): temporary context that overwrites durable state is a lifecycle miss; separate commitment, do not fuse. MemRiskBench (2609.14976): an average memory score is not a risk profile. Five categories — stale facts, conflicting updates, cross-user leakage, revoked-memory reuse, constraint decay — scored by deterministic trace checks with no LLM-as-judge on pass/fail; 120 scripted episodes; five local quantized models. A 78% average can still leak in 4% of episodes. A 20% risk-preserving subset keeps ranking (Spearman ρ = 0.975), risk coverage 1.0, and high-risk detection 1.0. Pair with AIM: who may read is one gate; whether the row is still authorized after revoke is another. Cairn (2609.19502): a private memory row is not a community fact about a shared tool, service, or data source. Time-decayed Beta with confidence shrinkage; query-before-use and evidence-backed rating after; adversarial sim (lying, collusion, camouflage) plus a production case study. One paper this window — keep it under lifecycle, do not open a second memory product. Pair with After the Party: download rank is not corroboration. AutoViewMem (2609.21940): mixed-slot memory is not a view. Discover low-overlap semantic views from traces, select a compact complementary set, extract provenance-grounded memories at write time, then run ordinary top-K. LoCoMo and PersonaMem under Qwen3-8B and Qwen3-14B beat strong memory baselines on long-horizon QA and personalization. One paper, no repo — do not open a views product. Pair with RD-Forget: disentangle at write, not at retrieve.
