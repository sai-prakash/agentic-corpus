# Context graph

**Definition.** A task-specific runtime projection assembled from governed knowledge, retained experience, live state, and policy. Usually built for one task and discarded.

**Contrast.** A context graph is not a third source of truth and not a product. Knowledge graph holds accepted assertions. Memory graph holds observations and outcomes. Context graph is the slice an agent is allowed to see *now*. Harness is the permission boundary around that slice.
