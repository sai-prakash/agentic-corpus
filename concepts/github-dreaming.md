# GitHub Dreaming

**Slug:** github-dreaming  
**Heat:** 4  
**Updated:** 2026-11-03

Out-of-band batch process that reviews past agent sessions and work to curate personal and repository memories, and proposes updates to skills or custom instructions via pull requests.

## Triple / contrast
Out-of-band dreaming for memory curation is not in-session reflection or a static CLAUDE.md file.  
It separates the cost of improvement from the critical path of the current task.

## Sources
- GitHub blog changelog "GitHub intelligence puts your code, context, and history to work" (28 Oct 2026)

## Shipable lab (6 h)
Log a few short agent sessions. Write a batch script that extracts recurring failures or preferences and emits proposed memory updates as markdown. Have a second session load the proposed memory and measure adherence or reduced rework versus baseline.
