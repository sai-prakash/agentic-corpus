# Skills over MCP

**Definition.** Serve Agent Skills (`SKILL.md` + supporting files) as MCP resources under `skill://`, listed and fetched on demand. Tools stay tools. Skills stay playbooks. One connection, two primitives.

**Contrast.** A tool schema is not a skill. Boot-loading every `SKILL.md` is not discovery. SEP-2640 (merged 13 Sep 2026, modelcontextprotocol#2640, identifier `io.modelcontextprotocol/skills`): `skills/list` returns a complete per-skill manifest (verbatim frontmatter + per-file resources with digests); `skills/get` returns any skill by URI, including ones absent from a partial listing; `resources/directory/read` is optional behind `directoryRead`. Hugging Face `hf-mcp-server` already implements the v1 wire contract. Cua Driver v0.28 serves desktop skills over the same stdio as the tools. Daniel San (14 Sep) is the public explanation, not the spec. LiteLLM MCP grants still apply: a missing allowlist is every server, and a skill that can `/add-mcp` is a grant surface. CapScope: ambient authority is a harness default; listing a skill does not pin who may run the tools it names. SkillsBench: loading the file can still drop a task the default solved. Skilder (2609.28693): listing is still not enforcement. Roles bundle skills + tools + limits; the same MCP server admits tools only inside a learned role. When discovery completed: 0 unauthorized tool calls / parameter violations (refund ceiling 60/60; out-of-scope Billing/PII 60/60). Tokens at 225 tools 9,084 vs 51,330 flat. Ordinary-task pass 82.5% vs 95.4% flat — pay the tax or do not call it governance. Pamela Fox (24 Sep, Copilot workshop): enterprise auth and tool-context cost are the questions the wire contract does not answer. ClaudeDevs plugin portal (25 Sep, x.com/ClaudeDevs/status/2103577007938228300 + claude.com/blog/build-plugins-for-claude): plugins package MCP and skills as one submission; claimed 110× MCP usage across Claude products this year; review + per-version install dashboards. Heat 3 first-party distribution trace — a store listing is not a grant, and a usage chart is not SEP-2640.

Peter Yang × Grok Bot leads (27 Sep, x.com/petergyang/status/2104213287353356531, 455 bookmarks): a designer bot with a file-layout skill talking to Figma MCP is the same two-primitive split — skill is the playbook, MCP is the hands. Heat 3 first-party practice, not a wire-contract change. Grok Build v1.0.43 surfaces unanswered MCP tool prompts in minimal mode — hosting the prompt is still not a grant.

Iwase (26 Sep, x.com/iwashi86/status/2103982958524739626, 1.7k bookmarks): an MCP server that only wraps an HTTP API or a CLI is not a primitive. A terminal agent that reads `--help` can call the API. Heat 3 vocabulary — pair with Thariq CLI-over-MCP. AgentWorld (agentworld.io/skill.md + MCP interface): the playbook is a skill file; the hands are REST or MCP. That is the two-primitive split on a research sandbox, not a reason to keep wrapper servers.

MCP Events in ChatGPT (Max Stoiber, 30 Sep, x.com/mxstbr/status/2105091392011948221, 246 bookmarks): a server can push messages/comments/status and trigger automations. Heat 3 shipping trace — a push event is not a grant, and an automation trigger is not SEP-2640 discovery. Pair with CapScope: ambient authority is still a harness default when the event arrives unsolicited.

Kong Context Mesh GA (30 Sep, x.com/kong/status/2105406105585127539 + developer.konghq.com/context-mesh/): Code Mode MCP searches the API surface, fetches schema on demand, and runs multi-step workflows in code instead of loading hundreds of static tool defs; vendor example ~99% token cut (120k → 1.2k). Heat 3 shipping trace — Code Mode is a surface ranking, not a grant. Visionary x AI (1 Oct) restates Events as event → agent → tool; recirculation of the Stoiber note.

Publish angle: one MCP server, two listings. `tools/list` is the hands. `skills/list` is the playbook index. Fetch one skill URI per task. Pin grants outside the server. Score with-vs-without the fetched file on a real reverted PR, not on a toy the agent already passes. Add a role-scoped arm: tools arrive only after the role is learned; report unauthorized calls vs flat injection tokens. A plugin portal is distribution, not the gate. Delete wrapper MCP that only re-exposes `--help`. A push event that starts an automation still needs the grant pinned outside the server.
