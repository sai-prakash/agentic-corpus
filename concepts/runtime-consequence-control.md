# Runtime consequence control

**Definition.** A model-free gate that maps each attempted tool or shell effect to a named consequence class and a per-(resource, class) trust state *before* the command runs. Registry scanners and skill-file linters are inputs to that ledger. They are not the decision.

**Contrast.** A clean scan is not a permitted action.
