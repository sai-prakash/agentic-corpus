# StarNet harness

Local-first desktop multi-agent harness whose pixel-art space station is a projection of live runtime state: rooms scope teams, hallways authorize handoffs, objects are real capability grants.

## Contrast
Spatial layout as the enforceable permission and workflow model is not a decorative skin over a shared chat + tool list.

## Lab seed
Stand up the sidecar. Create two agents in different rooms. Verify that a capability placed in one room is not available in the other, and that a hallway handoff is the only authorized transfer. Confirm the UI never claims state the event bus cannot prove.
