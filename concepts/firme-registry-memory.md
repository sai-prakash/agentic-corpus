# FIRME: Registry-Anchored Memory Graphs

**Slug:** firme-registry-memory  
**Heat:** 4  
**Updated:** 2026-10-31

Registry-anchored memory graphs reconcile heterogeneous observations to persistent canonical relationships while preserving source, time, and context.

## Triple / contrast
Identity-preserving registry memory is not flat episodic notes.  
Canonical relationships + aliases accumulate evidence across periods; surface-form variation does not fragment the graph.

## Sources
- arXiv:2610.40482 (Zhang, Gao, Shiao; submitted 29 Oct 2026) — paper

## Shipable lab (6 h)
Build a tiny registry: entity alias table + relationship nodes with provenance edges. Ingest 20–30 short multi-source notes (e.g., meeting notes + follow-up emails). Measure Correct Match Rate and reattachment recall against a pure vector store baseline on held-out queries that require identity continuity.
