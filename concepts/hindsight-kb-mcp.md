# Hindsight Knowledge-Base MCP

**Definition.** Native MCP surface for a self-healing knowledge-page wiki that sits on top of agent memory; the same connection used for retain/recall now exposes tools to browse, search, create, update, and prune the pages.

**Contrast.** Agent memory and its human-readable wiki are not separate integrations; the wiki is a first-class MCP tool surface on the memory connection.

**Evidence.** Vectorize Hindsight 0.9.2 (blog Aug 2026; X circulation 28 Oct 2026): seven agent-facing operations registered as MCP tools with safety annotations. Heat 3 (product + discourse). Updated 2026-10-29.

Sources: https://x.com/Vectorizeio/status/2115266062757281984, https://hindsight.vectorize.io/blog/2026/08/26/knowledge-base-mcp-tools.

Publish angle: connect an agent to a memory MCP that also exposes wiki CRUD, have it write and later revise a page about a recurring failure mode, and check whether the page stays consistent with the underlying memory.
