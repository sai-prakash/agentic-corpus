# Scope

**Definition.** Open-source platform for evaluating agentic coding experiences: tasks + criteria + profiles → live runs with structured pass/fail reports, driving existing agents (Copilot CLI, Claude Code, VS Code Copilot).

**Contrast.** Agent experience evaluation is not a model leaderboard and is not a single-shot pass rate. It measures how agents use a product across configurations, with reusable criteria and continuous DevAx loops.

**Heat.** 4. Updated 2026-10-20.

Sources: Microsoft announcement 19 Oct; https://github.com/microsoft/scope (MIT); microsoft.github.io/scope.

Publish angle: clone, run a hello-world Express criteria set against two agents, inspect the report, then change one profile element and re-run.
