# Agent harness

**Definition.** The runtime around a frozen model: tools, memory, planning, verification, budgets, lifecycle hooks. Not the model.

**Contrast.** A framework is one packaging of harness jobs. The harness is the job list and the IP.

**Heat.** 5. Updated 2026-08-26.

Sources: Philipp Schmid Jan 2026; arXiv 2606.20683; 2604.08224; StarHarness 2608.24804.

Publish angle: if swapping the model breaks the system, you built a dependency.
