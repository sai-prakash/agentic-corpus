# Agent harness

**Definition.** The runtime around a frozen model: tools, memory, planning, verification, budgets, lifecycle hooks. Not the model.

**Contrast.** A framework is one packaging of harness jobs. The harness is the job list and the IP. EvoHarnessBench (2609.04280): adding tools, skills, or specialist agents is a harness change that can *drop* previously solved tasks — agent-axis backward transfer −34.7% on the largest ALE deployment cell.
