# Agent harness

**Definition.** The runtime around a frozen model: tools, memory, planning, verification, budgets, lifecycle hooks. Not the model.

**Contrast.** A framework is one packaging of harness jobs. The harness is the job list and the IP. OpenAI's wording: humans scaffold the repo so agents can execute; the model is not the product. 0xnoonez: harness is what is *allowed*; context is what is *in view*; memory is what *survives*. Boeckeler / Fowler via Vinija Jain: vendor harness vs user harness; guides before the act, sensors after. Sid Jain (30 Aug): prompt tells, context decides the view, harness is the world. Same Model, Different Harness (2608.26218): tight-window context policy moves SWE-bench Verified F2PF 28% → 49% and complete solutions 43 → 72 with weights frozen. Self-orchestration (2608.26480): a manager-worker filesystem scaffold is a harness, not a multi-agent society — gains are real and model-conditional. SARA and Context Gets Root: tool observation is not authorization, and context assembly can grant root. openJiuwen (2608.27969): 82.6% SWE-bench Verified / 87.19% Terminal-Bench 2.1 by composing Rails and adapting runtime decisions around a fixed model policy. Logos (2608.28553): a plugin is a process; the shared object is an append-only transcript, not a co-resident heap. Hermes Agent v0.21.0 (31 Aug): Bot Mode, live subagent steer, cron that mutates persistent memory, transcripts that never re-append — a shipping harness, not a paper. Graft: onboarding the repo once is a harness job; grepping it every session is a tax. MNIST-PRO (2608.31022): Agentic MCP autonomy lifts Gemini-3.7-Flash Memory Canvas 68→88 / 38→63; adding persistent memory does not beat no-memory Agentic MCP (75.5→73.5). The harness that can write files is not the same object as a diary of last episode's procedure. David Ondrej via MaxForAI (1 Sep): once 20–30 agents share a repo the harness jobs become worktrees, push locks, read-only DB roles, and a manager queue — not a better system prompt. HarnessDev (2609.01437): a model can author a runnable harness from a weak seed, and that harness is often co-adapted to the author — Opus 69.3 → 33.0 on SWE-Pro when Gemini executes the same file because of a hard-coded 120-step cap. State and memory written into the harness were never hit in 26,679 traces. HEART (2609.01736): a 25k-function catalogue is not a context window; Tool Primitives hide schemas behind an LLM wrapper and a planner–router–verifier loop. Persistent Agents (2609.00546): the current model+harness pair is a binding, not the agent.

Publish angle: if swapping the model breaks the system, you built a dependency. If a tool observation can authorize the next write, you built an injection path. If a kill of one plugin kills every session, you built one failure domain. If persistent memory transfers a recipe and not an artifact, you stored a blog post. If the harness only scores under its author, you built co-adaptation. Benchmark the solver, not the checkpoint.
