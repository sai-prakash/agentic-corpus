# Agent harness

**Definition.** The runtime around a frozen model: tools, memory, planning, verification, budgets, lifecycle hooks. Not the model.

**Contrast.** A framework is one packaging of harness jobs. The harness is the job list and the IP. OpenAI's wording: humans scaffold the repo so agents can execute; the model is not the product. 0xnoonez: harness is what is *allowed*; context is what is *in view*; memory is what *survives*. Boeckeler / Fowler via Vinija Jain: vendor harness vs user harness; guides before the act, sensors after. Sid Jain (30 Aug): prompt tells, context decides the view, harness is the world. Same Model, Different Harness (2608.26218): tight-window context policy moves SWE-bench Verified F2PF 28% → 49% and complete solutions 43 → 72 with weights frozen. Self-orchestration (2608.26480): a manager-worker filesystem scaffold is a harness, not a multi-agent society — gains are real and model-conditional. SARA and Context Gets Root: tool observation is not authorization, and context assembly can grant root. openJiuwen (2608.27969): 82.6% SWE-bench Verified / 87.19% Terminal-Bench 2.1 by composing Rails and adapting runtime decisions around a fixed model policy. Logos (2608.28553): a plugin is a process; the shared object is an append-only transcript, not a co-resident heap. Hermes Agent v0.21.0 (31 Aug): Bot Mode, live subagent steer, cron that mutates persistent memory, transcripts that never re-append — a shipping harness, not a paper. Graft: onboarding the repo once is a harness job; grepping it every session is a tax.
