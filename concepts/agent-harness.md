# Agent harness

**Definition.** The runtime around a frozen model: tools, memory, planning, verification, budgets, lifecycle hooks. Not the model.

**Contrast.** A framework is one packaging of harness jobs. The harness is the job list and the IP. OpenAI's wording: humans scaffold the repo so agents can execute; the model is not the product.

**Heat.** 5. Updated 2026-08-27.

Sources: OpenAI harness engineering (Feb 2026, recirculating); Philipp Schmid; arXiv 2606.20683; 2604.08224; StarHarness 2608.24804; walkinglabs/learn-harness-engineering; santtiagom roadmap.

Publish angle: if swapping the model breaks the system, you built a dependency.
