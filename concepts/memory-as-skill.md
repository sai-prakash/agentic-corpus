# Memory as skill

**Definition.** Distilled experience rides the same progressive-disclosure carrier as a capability skill: a short resident description (L0), an on-demand index and policy (L1), detailed `reference/*.md` (L2). Reads share the path. Writes fork — history appends; current state rewrites and revalidates.

**Contrast.** A second memory product is not required if the skill folder already has L0→L2.
