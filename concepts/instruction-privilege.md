# Instruction privilege

**Definition.** The source label on a context block — system, user, tool, memory — and the rule that a later assembly step may not raise that label.

**Contrast.** Instruction hierarchy is not a harness. The model ranks sources; the harness rebuilds the prompt and can promote a tool observation into a user or system instruction. Context Gets Root (2608.27299): tool-to-user and tool-to-system escalation complete 13 CIA/RCE objectives on six coding-agent harnesses. SARA: a tool output that names an action is a command, not data. Pillar: the loop, registry, compaction, and session log outrank the agent. Compaction that re-roles a block is escalation. Compaction that shortens a block is policy.
