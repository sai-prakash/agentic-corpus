# Evals & gates

**Definition.** Independent checks that keep or reject a harness change, a tool call, or a session outcome. Not a paragraph in the system prompt.

**Contrast.** Name-match tool evals are not scenario evals. Agent Seer synthesizes graded multi-turn dialogues from an MCP spec alone; the failure that matters is argument values. Harness-Bench scores the *pairing* (model + harness), not the weights. Same Model, Different Harness makes that pairing the experimental unit: tight-window policy moves F2PF 28 → 49 with frozen weights. AgentJudgeBench: LLM judges on workflow-DAG tool-calling hit a 77–82 ceiling on hard queries without gold, and gold can over-anchor frontier judges. BTS-AgentBench compiles read-only telemetry into replayable episodes with tool-derived gold. MemToC: arbitration evals must condition on source correctness — models keep a true memory against a false tool 6.5–17.1% of the time. Predictable harness: schema-validate the plan *before* tools or the free-text plan is the leftover noise. Agent Mesh: retry/timeout/error-rate breakers assume idempotent messages; delegations are not messages. HarnessLens: the gate on a harness edit is attributable behavior, not a mean score. GCPC (2608.27487): pass@1 hides skill effects — of 879 pairs whose official outcome does not change, 20.9% still move >0.10 up and 18.7% move the same amount down. DoCtOR (2608.28264): the gate on multi-agent reflection is *who* may write the lesson; reflecting every agent contaminates the ones that were not the decisive error. EvoUndo: add recoverability as a second gate beside capability. Warp: the gate on a skill edit is a reviewable PR against `SKILL.md`, not an in-session rewrite the next turn will treat as ground truth. Harness-of-Harness: the tests the implementer writes during the loop are not the evaluation that accepts the iteration. HarnessEvolve: two explicit gates — quality (leakage ≤ 0.8, in-context examples ≤ 5) and performance (current-batch lift without recent-batch drop > 0.025) — plus a held-out snapshot pick. HarnessDev (2609.01437): a harness that reports success is not a pass — score diffs and environment state. Self-Eval and Unified-Eval must both be reported; feedback-set lift is not a selection gate (2 of 9 self-chosen finals were held-out best; 2 of 64 version switches cleared rerun noise of ±4.75). DNative-Twin (2609.03787): replay without the tool-state contract cannot decide an unobserved divergence. MCP-to-A2A (2609.01693): protocol evals measured apart do not describe the joined hop; deterministic field-egress scoring, no LLM judge. SWE-Gate (2609.04167): of 644 functionally passing repairs, 221 fail review constraints mined from real PR comments. Functional CI is one gate; the review is another, and it has to be executable. DRACO (2609.04094): a trajectory-level rubric is not credit assignment — redistribute the score onto the cited steps or the long-horizon agent is trained on a coin flip. Research swarm (2609.04170): an eval the agents can write into a shared library is an exploit the next agent will load. ClaimReceipt (2609.01992): sufficiency (can you recompute the claim from retained evidence) is not coverage (do the files cover the committed set). A missing receipt is INCONCLUSIVE, not a pass. ToolGate (2609.02067): a generated scientific item is a proposal until an executable script reproduces the answer in the tool, no-tool screens fail, and a tool-using agent still needs the software. RealSWE (2608.27831): a padded GitHub issue is not a real ask — realistic composition drops resolution 6.4 pp and can reorder models; Desired Behavior and Motivation move the score, Environment Information and Reproduction Steps do not. BCIT (2608.26730): a past training win is not a gate on the current parent — 13/24 naive reuses failed the new context. A terminal pass/fail is not a credit assignment.

Publish angle: score the solver. Condition memory-vs-tool tests on which source is actually correct. Do not let every agent write after a failure. Do not admit a harness or skill edit that you cannot undo on a second state, that lifts this batch and drops the last ones, that only runs under its author, that passes tests and violates the review, or that cannot abstain when a receipt is missing. Prefer a small PR over a silent self-edit. Do not let the harness grade itself.
