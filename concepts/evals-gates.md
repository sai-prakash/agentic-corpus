# Evals & gates

**Definition.** Independent checks that keep or reject a harness change, a tool call, or a session outcome. Not a paragraph in the system prompt.

**Contrast.** Name-match tool evals are not scenario evals. Agent Seer synthesizes graded multi-turn dialogues from an MCP spec alone; the failure that matters is argument values. Harness-Bench scores the *pairing* (model + harness), not the weights. Same Model, Different Harness makes that pairing the experimental unit: tight-window policy moves F2PF 28 → 49 with frozen weights. EvoHarnessBench (2609.04280): the gate on a catalog change is backward transfer on *already solved* tasks, not only the new pass rate. Deployment and adaptation can disagree. Memory portability (2609.05339): a store-only repair of NOTES misses 90% recovery in 48/48; keep the raw history or you cannot gate a model swap. PlanFence (2609.03340): freshness of shared state is not a gate on the pending action. MASkills: a skill edit that fails held-out validation rolls back. ClaimReceipt (2609.01992): a missing receipt is INCONCLUSIVE, not a pass. SWE-Gate (2609.04167): of 644 functionally passing repairs, 221 fail review constraints. A terminal pass/fail is not a credit assignment. Interchangeability (2609.05279): swapping a role-matched agent barely moves task score and still raises communication per unit of progress 16–63%. A placebo roster shuffle is the control; greedy decoding shrinks both drift and the swap tax; longer formation history grows both. Outcome fungibility is not a coordination gate. Multi-Harness RL (2609.04518): pooling several coding harnesses inside one GRPO group is not a portability gate. Across 24,000 sealed SWE-bench Verified evals the *evaluation harness* moves mean solve rate 2.14% → 9.27% (×4.3); the training recipe moves it by 1.16. Cross minus Within on a held-out minimal harness is +0.25 pp, 95% CI [−0.48, +1.02], and seed ranges exceed that difference. Cross's advantage still names the generating harness (+4.48 pp over shuffled labels); Within's does not; both rules match held-out score and in-harness action mix. State the grouping boundary; test under an unseen cage. World-acting review (2609.04894): action-interface expansion is documented more than completion, recovery, authorization, or independent verification. EAL-Bench (2609.01836): a memory row that mints authority is a failed authorization gate — writers invent false grants on up to 50.2% of unauthorized requests; executors fire 98.6% of those rows. Verification Tax (2609.04681): coding-activity lift is not production-qualified change. The gate is reviewer-hours and residual risk, not tokens generated.

Publish angle: do not admit a harness or skill edit that adds a tool and silently fails yesterday's ticket, that cannot abstain when a receipt is missing, or that fires a plan whose cited records have moved. Do not let the harness grade itself. Do not treat a role-matched swap as free because the scoreboard did not move. Do not treat Cross-harness GRPO as portable capability until an unseen cage agrees. Do not treat a memory write as a grant.
