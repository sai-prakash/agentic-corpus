# Recoverable harness

**Definition.** A harness change is admissible only if a later process can restore a typed observational equivalent of the pre-change state on states other than the one where the change was made.

**Contrast.** Capability gain is not recoverability. EvoUndo (2608.28363): 197 of 600 one-shot mutations improve the score and then fail recoverability verification; conventional repair recovers 0/197 under the original recovery language. Logos (2608.28553): shared memory inside one process is a single failure domain — an append-only transcript plus peer processes lets eighty sessions resume with no repeated effect after kills at the four tool-call boundaries. Nash / Second Mind: a recovery file that a fresh session can read is operational state; a conversation the next session must reconstruct is only history. Full snapshots fail selective undo because they clobber later edits. HarnessEvolve (2609.00829): the performance gate is a weak recoverability proxy — refuse an edit that lifts the current batch and drops recent ones, then pick a held-out snapshot. That stores competence across batches; it is not yet a typed restore on a second state. HoH versioned project histories make the iteration addressable; they do not by themselves prove that iteration 69 can still authorize iteration 1's contract. Persistent Agents (2609.00546): identity, private memory, and versioned body are the continuity-bearing substrate; model, harness, host, and surfaces are a binding you may replace after pause–save–validate–attach–load–run. Clean-room frozen commit: 833 + 92 tests. Mechanical move is shown. Behavioral sameness after the move is explicitly not shown. HarnessDev: generated harnesses declared checkpoints that never fired in 26,679 traces — a restore hook that is never reached is documentation. Terminal-Universe (2609.04148): file ops in a trace are enough to restore the *pre-edit* workspace and then complete the missing tree. That is recoverability of the environment from the log, not recoverability of a harness mutation. A trajectory you cannot replay into a room is only a blog post about work.

**Heat.** 5. Updated 2026-09-05.

Publish angle: 6h lab — mutate one surface, capture a witness, replay undo on a second state *and* under a second binding (other model or host). Admit the mutation only if both restores match the contract. If all you have is a trace, recover the pre-edit files before you call the run training data.
